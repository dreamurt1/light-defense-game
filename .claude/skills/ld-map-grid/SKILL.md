# 격자 맵 만들기 (2026-11-23 밤 나들이 v3)

정본: `docs/design/NIGHT_RUN.md` 7절 · 사전 `src/data/obstacles.json` · 로직 `src/systems/grid.ts`(검사·덩어리·빛 차단) · `src/systems/pathfind.ts`(A*).

## 1. 규격
- **33×19칸, 한 칸 96px**, (0,0) 왼쪽 위, 칸 중심 = 칸×96 + 48. 중앙 광원 (1600,900)은 광장 가운데 칸 (16,9).
- **광장** = 열 13~19 × 행 6~12, 모두 `C`(늘 비움).
- **가장자리 칸**(0·18행, 0·32열) = 둘레 띠: 덩어리 장애물(바위·집·술통·건초·풀숲·등불 자리)을 두지 않는다. 강·울타리·다리는 지나가도 됨. 루미가 노는 칸은 1~17행 × 1~31열(걷는 영역 위 100·옆 100·아래 110), 행렬은 가장자리 밖에서 들어온다.
- **등불 자리 `L` 정확히 4개**, 광장 가운데 (16,9)에서 **가로·세로 중 큰 값으로 4~8칸**(직선거리 아님).

## 2. 장애물 사전 (크기는 [폭, 높이], 돌려도 됨)
| 문자 | 종류 | 크기 | 걷기 | 빛 | 비고 |
|---|---|---|---|---|---|
| `.` | 바닥 | | ✓ | | |
| `C` | 광장 | 7×7 | ✓ | | |
| `R` | 바위 | 1×1, 2×2 | ✗ | 막음 | |
| `H` | 집 | 2×2, 3×3, 2×3 | ✗ | 막음 | 뒤에 가면 반투명 |
| `T` | 술통 | 1×1 | ✗ | 막음 | 붙어 있어도 칸마다 하나 |
| `Y` | 건초 | 2×1, 3×1 | ✗ | 막음 | 임시 코드 그림 |
| `F` | 울타리 | 폭 1, 길이 n | ✗ | 막음 | |
| `W` | 강 | 폭 1, 길이 n | ✗(나는 적만) | 안 막음 | 다리 필수 |
| `B` | 다리 | 1×1 | ✓ | 안 막음 | 강 위에만 |
| `G` | 풀숲 | 2×2, 3×3 | ✓(은신) | 안 막음 | |
| `L` | 등불 자리 | 1×1 | ✓ | | 맵당 4 |
이어진 같은 문자의 **직사각형** = 장애물 하나. 직사각형이 아니거나 사전에 없는 크기면 검사 실패.

## 3. 순서
1. `src/data/maps/<id>.json`: `{ "id", "name", "band": "A|B|C", "theme": "light-village|border|dark-village", "rows": [33글자 × 19줄] }`.
2. `src/data/index.ts`에 `import map<id> from './maps/<id>.json'`을 더하고 `GameData.maps` 목록에 넣는다.
3. `npm run check:maps` → 통과할 때까지(실패하면 어느 칸인지 나옴). `npx vitest run tests/maps.test.ts tests/map.test.ts`.
4. 헤드리스로 본다: `http://localhost:5173/?autoplay=9999&night=4&map=<id>&idle` (테스트 판처럼 기록에 남지 않음). 카메라를 멀리 빼 통째로 찍는 예: `cam.setZoom(cam.width / 3300); cam.centerOn(1600, 900)`.
5. `src/data/nights.json` `bands[].maps`에 넣는다(구간 A 밤 1~2 · B 3~5 · C 6+). 같은 맵은 두 밤 연속 나오지 않는다.
6. 기록: `docs/DECISION_LOG.md` 한 줄, 스킬 문서 동기화 `npm run doc:skill`(맵 JSON도 복사됨).

## 4. 자주 틀리는 것
- 광장(13~19 × 6~12)을 침범 — 한 칸이라도 `C`가 아니면 실패.
- 폭 2 울타리·강 (`FF` 두 줄) — 울타리·강은 폭 1.
- 다리 없는 강, 다리가 강 줄 밖.
- 등불 자리가 3개·5개이거나 너무 가깝거나(3칸) 멂(9칸), 막혀 못 가는 칸.
- 가장자리 칸의 풀숲·바위(2026-11-23 B1 풀숲을 한 줄 위로 옮긴 일).
- 1×1 풀숲 — 풀숲은 2×2부터.
- 걷는 칸이 광장과 이어지지 않음(울타리·강으로 닫힌 방).
- 켜진 등불의 결계(반지름 최대 200)가 좁은 통로를 막으면 걷는 적이 돌아가야 한다 — 길찾기는 결계 안 칸을 피하므로 막다른 길이 되지 않게.
