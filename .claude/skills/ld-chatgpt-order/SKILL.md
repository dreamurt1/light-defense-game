# ChatGPT 의뢰서 묶기

역할: 기획·규격은 Claude, 그림은 ChatGPT. 라이언이 묶음을 ChatGPT에 올린다. 보내는 문서도 내 쪽 오류·모호함이 없는지 먼저 본다(예: 좌우 기준이 섞인 표현).

## 1. 폴더
- 저장소: `hand-offs/chatgpt-<주제>-YY-MMDD-HHMM/` — `order-<주제>.md`(의뢰서) + 안내 그림(PNG) + 필요하면 `README.md`(라이언용).
- 고치면 폴더 이름 시각도 수정 시각으로(`git mv`, 가리키는 경로 함께).
- station: `node scripts/station.mjs --from <저장소 폴더> --add <기준 사실서, 컨셉, 팩 zip…> --readme <안내 txt>` → `C:\Users\user\Desktop\file_station_for_ryan\<같은 이름>\`. 대체된 옛 묶음은 station에서 지우고 보고에 알린다.

## 2. 의뢰서 틀 (`order-<주제>.md`)
1. 머리: 같이 올리는 파일 목록, "앞선 의뢰서와 다르면 이것을 따른다".
2. 왜(라이언이 본 것 + Claude가 잰 것, 숫자로).
3. 만들 것(장 수·방향·크기·파일 이름).
4. 꼭 지킬 것(표).
5. 파일 구조·manifest.
6. **영문 프롬프트**(그대로 붙여 넣기용, 코드 블록).
7. 받은 뒤 Claude가 잴 것.

## 3. 늘 넣을 기준 (해당되면)
- 캔버스 512×512 투명, 발끝 y 496, 한 팩 한 축척. 크기를 못 맞추면 비율 지켜 더 크게(Claude가 줄임).
- **토리 귀 규칙(2026-11-27 라이언)**: 토리 입장: 오른쪽 귀가 펴져 있고 그 귀에 민트 리본과 별, 왼쪽 귀는 접혀 있다(우선). 유저 입장(토리가 보는 사람을 향할 때): 화면 왼쪽 귀 펴짐 + 리본, 화면 오른쪽 귀 접힘. 등을 보이거나 왼쪽을 볼 때는 화면에서 좌우가 바뀐다. 방향별 펴진 귀(= 리본 자리): 000·045·090 = 화면 왼쪽 / 135·180·225·270·315 = 화면 오른쪽(지금 스프라이트의 펴진·접힌 귀 자리 그대로). 리본이 접힌 귀에 있으면 틀림 (2026-11-27 15:44 라이언 최종). 의뢰마다 `hand-offs/character-canon-26-1127/``2_tori_concept.png`(+ 기준서 `light-defense-canon-v2.md`)를 붙인다. 왼쪽 방향 뒤집기 금지. 눈은 대기 그림 눈 그대로(짙은 남보라 세로 타원) — **"대기 눈을 덧붙이지 말고 한 번만 그려 겹친 윤곽이 없게"**.
- **눈 색은 그림 생성으로 고치게 하지 않는다**(2026-11-18: 다시 그릴 때마다 속눈썹이 바뀌고 '색만 바꿔'는 안 먹힘). 걷기 의뢰엔 `hand-offs/chatgpt-tori-eye-fix-26-1118-1600/tori_eye_fix.py`를 함께 보내 "그리기 → 스크립트 → `RESULT: ALL OK` → `*_eyefix` zip, 출력 전문을 답에"로. 스크립트를 고치면 같은 계산을 크롬 캔버스로 먼저 시험(파이썬은 이 PC에 없음).
- **f01은 이번에 첨부한 대기 그림만**: ChatGPT가 예전 자기 팩(`Tori_Idle_8Directions_512`, 135°가 옛 그림)을 쓰고 manifest엔 "byte-for-byte"라 적은 일이 있었다 → 대기 zip을 늘 첨부하고, 스크립트의 `--idle` 점검으로 확인.
- **걷기**: 방향마다 4장, f01 = 대기 그림 복사, 한 바퀴. 게임 박자 f01 f01 · f02 · f03 · f04 f04(토리 약 0.56초, 도토 약 0.6초). 뜨는 높이 약 6px, 눈 높이 ±6, 귀 끝 ±15. 제자리(몸 x 256 둘레).
- **도토**: 뒤집기 허용, 몸(꼬리 말고)을 가운데에.
- **루미**: 등불을 들지 않음.
- **홈·배경**: 캐릭터·글자·버튼 없음(게임이 얹음), 구역·잘리는 선은 `docs/design/HOME_SCREEN.md`. 화면 4종(PC 풀·PC 세로·모바일 세로·모바일 가로).
- 금지: 그림자·글자·소품·서명, 흰·검은 배경(투명, 안 되면 #FF00FF), 다른 동물 주인공.
- 기준 사실서 `hand-offs/chatgpt-canon-*/light-defense-canon.md`를 함께(기획이 바뀌었으면 먼저 고침).

## 4. 안내 그림
- 헤드리스 캔버스로 만든다(`scripts/lib/chrome.mjs`의 openPage → canvas 그리기 → screenshot). 지금 그림 위에 선·숫자(− = 위, + = 아래, 512 기준)를 얹어 "무엇을 어떻게"를 보이게.
- 예시: `hand-offs/chatgpt-tori-walk-fix-26-1118-1423/`(움직임·눈 비교), `hand-offs/chatgpt-home-bg-26-1118-1440/`(화면 4종 와이어프레임·구역).

## 5. station 안내 txt (`읽어보세요(올리지 않음).txt`)
- [왜] 한두 줄 · [올릴 파일 N개] 순서대로(10개 넘으면 앞 10개 먼저) · [메시지] 붙여 넣을 한국어 한 줄 · [확인할 것] 2~4개 · 마지막 줄 "받은 그림은 바탕화면 어디든 두고 Claude Code에 알려 주세요".
