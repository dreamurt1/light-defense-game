## 넣은 자리

- 파일: `public/ui-icons/icon-*.png`(그대로 복사 — `public/assets`는 `npm run assets`가 지우고 다시 쓰므로 따로), 코드 `src/ui/v3Icons.ts`.
- 쓰는 곳(지시서 2-3): HUD ✦·★ = 선(28px 이상) · 아침 요약(별가루 +n·빛 레벨) = 이번 밤에 늘었으면 `-on`, 아니면 선 · 아침 상점 준비물 4칸 = 챙긴 것만 `-on`, 값의 ✦ = 선 · 결과 별가루 = 모았으면 `-on` · 두 길 점(결과·아침 길 제목, 지난 밤들) = 선만(`icon-path-keep` = 자비 길, `icon-path-expand` = 돌려보냄 길, 중립은 회색 점 그대로) · 홈 칩·홈 상점의 ✦ = 선.
- 준비물 id ↔ 아이콘: `lamp_oil` ↔ `icon-prep-lamp-oil` 등(밑줄 → 붙임표).
- 옛 SVG(`src/ui/icons.ts prepIcons`)는 지우지 않음.
