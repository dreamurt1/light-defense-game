# LIGHT DEFENSE Map Props Pack

Map props for the LIGHT village and DARK/BORDER regions. PNGs are transparent; each map cell is 96 px with a 48 px margin on every side. House canvases reserve an additional 96 px above the footprint for the roof.

Style: hand-painted 2.5D, slightly tilted top-down view, broad readable shapes, plum outlines, warm amber light for the light village and muted midnight/violet or teal for dark and border regions.
