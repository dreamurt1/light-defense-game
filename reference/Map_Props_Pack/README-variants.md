# LIGHT DEFENSE Map Props — Remaining Theme Variants

17 transparent PNG variants derived from their matching LIGHT assets, preserving each canvas, footprint, and silhouette. Isolated stray transparency fragments were removed during palette conversion.

- `border`: muted cool slate-blue for rocks, houses, fences, and hay; house windows retain restrained amber light.
- `dark`: deep indigo/plum for rocks, barrel, hay, and bushes.

All files use the 96 px map-cell scale and the original 48 px outer margins. Houses retain the additional 96 px roof allowance. These are optional 4-3 variants from the remaining-art order.

See `manifest-variants.json` for dimensions, footprints, and orientations.
