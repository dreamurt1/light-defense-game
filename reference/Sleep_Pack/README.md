# Sleep Pack

LIGHT DEFENSE 주인공 셋의 잠든 모습입니다. 쓰러짐은 사망이 아니라 잠깐 잠든 상태로 표현합니다.

- 512×512 투명 PNG, 오른쪽을 향한 옆모습
- 누운 몸의 바닥선 y=496, 몸 중심 x=256
- 눈은 편안하게 감고, 상처·X 눈·혀·별·멍은 없음
- 글자와 `zzz`는 그리지 않음(게임이 별도 표시)
- 바닥 그림자 없음

## Files

- `lumi_sleep.png` — 루미, 주황 스카프와 별 목걸이, 꼬리를 몸에 감음
- `tori_sleep.png` — 토리, 자신의 왼쪽 리본 귀가 위로 오도록 오른쪽 옆구리로 누움
- `doto_sleep.png` — 도토, 별 도토리를 안고 줄무늬 꼬리를 몸에 두름
