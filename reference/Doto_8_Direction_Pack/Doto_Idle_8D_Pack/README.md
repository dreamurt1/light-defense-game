# Doto Idle 8-Direction Pack

Eight 512×512 transparent PNG idle sprites for Doto, plus the original turnaround sheet.

## Directions
- 000° front
- 045° front-right
- 090° right
- 135° back-right
- 180° back
- 225° back-left
- 270° left
- 315° front-left

## Alignment
A single shared scale was applied to all eight cutouts. The bottom of each sprite is aligned to y=496.
Horizontal placement is centered on the full silhouette, including the tail. All eight views were drawn separately on the turnaround sheet; no mirroring was applied. Please have Claude Code check body-center alignment before importing.

## Contents
- Eight `doto_idle_*.png` sprites
- `sheet/doto_idle_sheet.png` original 8-view sheet
- `manifest.json`
