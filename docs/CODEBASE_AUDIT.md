## 0. 요약

새 기획은 게임의 뼈대가 바뀐다. 지금 코드는 **"등불지기가 들고 다니는 등불 HP 하나를 120초 동안 지키는 밤"**이고, 새 기획은 **"중앙 광원과 등불 스테이션(1~4개)을 지키고 켜며, 주인공이 HP·하트 3개·LP(빛 자원)를 갖고, 광도 4단계·지역 3개·세 무리의 적(잃어버린 주민·호스틸·패시브)과 자비 점수가 있는 스테이지형 로밍 디펜스"**다.

그래도 버릴 것은 많지 않다. 두 스틱 조작·조준 원뿔·루미 8방위 그림과 동작·이동과 장애물 판정·빛 부채꼴 판정·연출·에셋 가져오기 파이프라인·화면 틀과 가로/세로 배치·개발 도구는 그대로 쓴다. 새로 만들거나 크게 고칠 곳은 **판 규칙(자원·승패·스테이지), 적 AI와 분류, 광도 모델, 맵 데이터, HUD·결과 화면, 데이터 JSON**이다.

## 2. 지금 구현된 게임 기능

**플레이 (PlayScene 529줄)**
- 한 판 = 하룻밤 120초(초저녁 0~40·한밤중 40~90·새벽 전 90~120), 120초를 버티면 클리어.
- 마을 3200×1800, 카메라가 루미를 따라감, 바위·술통·등불 기둥 장애물(통과 불가), 풀숲 8곳(숨으면 이웃이 못 보고 맴돎, 빛을 쏘면 1초 드러남), 마을 둘레 집 줄·덤불 띠.
- 루미: 8방위 정지·걷기(ChatGPT 팩), 공격·피격·부활 동작 효과, 잠듦(KO), 128 칸, 이동 225.
- 조작: 왼쪽 이동 스틱 / 오른쪽 빛 스틱(끄는 거리에 비례한 원뿔 반지름, 놓으면 발사, 짧은 탭 = 자동 조준) / PC는 WASD + 마우스 끌기.
- 빛: 루미 중심에서 60° 부채꼴이 0.25초에 퍼짐, 대기 0.4초, 넉백 70·스턴 0.3초.
- 등불: 루미가 손에 든 등불 HP 100(이웃이 붙으면 깎임, 0이면 판 끝). 맞으면 루미가 밀리고 화면 흔들림.
- 이웃: **파닥(박쥐)만 구현**(지그재그, 무리). 화면 가장자리 밖에서 나와 등불을 쫓음.
- 콤보(2초 유지, 5마다 배율 +0.5, 끊기거나 맞으면 절반), 시너지 게이지 → 대광원(전방위 3배).
- 마을 분위기: 밤이 갈수록 밝아짐(진행²), 등불이 맞으면 어두워짐, 회복 시 밝아짐.
- 점수: 이웃 점수 × 콤보 배율, 클리어 +1000 + 남은 HP×10.
- 홈의 `테스트` 판(이웃 없음·시계 멈춤).

**화면**
- 스플래시, 홈(오늘 밤 등불지기·지난 밤들·상점·테스트·설정), 등불지기 선택(5명, 루미만 열림, 장착물 4개는 보여 주기만), 상점(준비 중), 지난 밤들(로컬 랭킹), 설정(배경음악·효과음·진동 스위치 — 소리는 아직 없음, 닉네임, PC 가로 화면, 전체 화면), 일시정지, 결과(새벽 / 오늘 밤은 여기까지), 보스 체력바(미리보기만).
- 세로 540×960 / 가로 높이 540·폭 720~1280, safe area, 판 중 회전 시 자동 일시정지.

**없음**: 다른 이웃 5종, 아이템, 장착물 효과, 방해 요소(안개·달그림자), 노월 보스, 소리·진동, 해금, 원격 랭킹, 튜토리얼.

**성능**: fps 상한 60, 정적 도형은 텍스처로 구워 씀(2026-11-06 버벅임 대응).

## 3. 최신 기획과 기존 구현의 차이

### 3-1. 영역별 비교

판정: 유지 · 수정(고쳐 씀) · 교체(새 것으로) · 신규 · 삭제

| 영역 | 최신 기획 | 지금 구현 | 판정 |
|---|---|---|---|
| 한 판 | 스테이지 약 100초, 끝 = 아침, 진행 70%부터 클라이맥스 | 하룻밤 120초, 시간대 3개 | 수정 |
| 진행 | 스테이지 여러 개(등불 1→4개), 친구 구출 스테이지, 보스 특수 스테이지, 맵 3종(스테이지 테마) | 같은 판 반복 | 신규 |
| 지킬 것 | 맵 가운데 고정 **중앙 광원**(최후 보루) + **등불 스테이션** | 루미가 들고 다니는 등불 HP | 교체 |
| 주인공 자원 | **HP + 하트 3 + LP**(빛 자원, 광도와 비례, 최소 '낮음') | 주인공 HP 없음, 빛은 무한(대기 시간만) | 신규 |
| 패배 | 하트 소진, 또는 중앙 광원 꺼짐 | 등불 HP 0 | 교체 |
| 승리 | 기본 승리 / 완전 승리(광원·등불 모두 '밝음' 이상, 2~3배) / 보스 HP 0 | 120초 버티기 | 교체 |
| 광도 | 4단계(낮음·중간·밝음·크게 밝음, 중간값 허용). 맵 전체·지역·주인공 주변·광원·등불이 각자 광도를 가짐 | 마을 분위기(밝아짐·어두워짐) + 등불 글로우 + 빛 마스크 | 모델 신규, 표현은 재사용 |
| 맵 | 빛의 마을 / 경계 / 북쪽 어둠의 마을, 구획 배치, 바위·건물·울타리·강+다리, 풀숲 | 마을 하나, 바위·술통·등불 기둥·풀숲 | 수정 + 신규 |
| 풀숲 | 숨으면 먼 몹이 못 봄, 주인공 자체 광도 때문에 일정 시간 뒤 드러남 | 무기한 숨기(빛을 쏘면 1초 드러남) | 수정 |
| 이동 | 왼쪽 스틱(좌우 바꾸기 가능) | 왼쪽 스틱 고정 + WASD | 수정 |
| 공격 | 드래그로 방향·반경, 놓으면 발사, 이동 중 가능, LP 소모 | 같음(끈 거리 비례 반경), LP 없음 | 유지 + LP 연결 |
| 반자동 | 적이 가까이 있을 때 탭 한 번. 대상이 없으면 오발 없음(인수 조건) | 탭 = 가장 가까운 이웃(사거리 밖도), 아무도 없으면 바라보는 쪽으로 발사 | 수정 |
| 적 무리 | 잃어버린 주민(구출 → 마을로 귀환) / 어둠의 호스틸(→ 맵 밖으로) / 패시브(비공격, 자비) / 보스 | 어둠에 변한 이웃 6종, 모두 같은 '되돌림' | 교체 |
| 적 종류 | 잃어버린: 개구리·고슴도치·레서판다 / 호스틸: 박쥐·웨어울프·뱀파이어 / 패시브: 올빼미·나방·반딧불이 / 보스: 노월 | 파닥(박쥐)만 구현, 그르르·말랑·호오·킥킥·노월은 데이터만 | 박쥐·노월만 이어짐 |
| 적 행동 | 주인공·중앙 광원·등불을 위협, 빛에 움찔·눈 가림·감속·등불 회피, 필살기(감속·HP 밀어냄·LP 감소·방어=자기 HP 증가) | 등불(=주인공)만 쫓아 붙어 피해, 넉백·스턴 | 수정 |
| 패시브·자비 | 길·아이템 자리를 막음, 공격하지 않고 지나가면 자비 점수(호스틸보다 큼), 반복 공격하면 호스틸 급증(분노), 대사 | 없음 | 신규 |
| 아이템 | 소모형 5종(바람 깃털·별 목걸이·반딧불 병·황금 도토리·빛의 부적), 시작 전 설정 + 맵에서 획득, 1회 사용, 광도 '중간' 이상 구역·등불·경계에서 스폰 | 데이터 2종(반딧불 병=등불 회복, 별사탕), 코드 없음 | 신규 (이름 겹침 주의) |
| 장착물 | 없음 | 4종(데이터·선택 화면 표시만) | 삭제 → 아이템으로 대체 |
| 시너지·대광원 | 없음 | 구현됨 | 삭제 |
| 콤보 | 일정 시간 안에 여러 몹 → 콤보, 유지 중 모든 점수에 추가 | 2초 유지, 끊기거나 맞으면 절반 | 수정 |
| 점수 | 등불 켜기(낮음) < 호스틸(기본) < 잃어버린 주민(높음), 자비 > 호스틸, 보스 최고, 완전 승리 2~3배 | 이웃 점수 × 배율, 클리어 보너스 | 수정 |
| 캐릭터 | 루미(기본), 토끼·다람쥐(구출 후 해금), 더 없음 | 루미·토리(토끼)·도토(햄스터)·바루(카피바라)·몽이(강아지), 특성·해금 조건 | 교체 |
| 세계관 | 빛의 마을 vs 어둠의 마을, 중앙 광원 파편으로 얻은 힘, 친구 구출, 노월 = 어둠 주민의 터전을 지키려는 보스, 공존 메시지 | 태양이 잠든 반딜마을, 어둠 = 잊힘, 노월 = 태양을 쉬게 하려던 선의 | 수정 |

| 화면 방향 | 웹·모바일 가로 기본, 세로도 제공, 설정에서 가로/세로 | 휴대폰 = 기기 방향, PC = 가로 기본(설정으로 세로), 두 방향 모두 배치 완료 | 거의 유지 |

### 3-2. 인계 문서 ↔ 원본 XMind

- 인계 문서가 **더한 것**: 잃어버린 주민 '여우', 호스틸 '삵' — 원본에 없음 → 라이언 결정으로 넣지 않음.
- 인계 문서가 **빠뜨린 것**: 패시브를 여러 번 공격하면 호스틸이 기하급수로 늘어남(분노) / 패시브 대사("너무 밝아..", "싸우기 싫어..", "저 빛이 무서워", "우리도 여기서 살고 있어") / 스틱 좌우 바꾸기 / 첫 화면은 중앙 광원과 주인공을 비춤 / 등불은 HP 없이 LP 게이지로 표시 / 등불 위치는 랜덤이되 외곽(패시브와 마주치게)·중앙 광원에서 너무 멀지 않게 / 맵 전체 광도가 등불보다 크면 등불은 그것을 따름 / 주인공 주변 광도는 기본 '크게 밝음', 진행할수록 넓어지고 HP 0이면 '낮음' / 중앙 광원은 '중간'에서 시작해 커지며 HP·LP를 회복시킴 / 진동.
- 원본이 **이미 답한** 인계 미결 질문: Q1(추가 캐릭터 없음), Q5(등불 켜기는 남은 LP와 관계없이 되고 쏜 뒤 LP·광도 감소 = 소모함), Q7(등불은 HP 없음, 중앙 광원은 HP와 광도 비례), Q13(방어 = 적 자신의 HP 증가).
- 원본 안의 작은 모순: 납치된 친구 "토끼, 강아지 등" ↔ 플레이어블 "토끼, 다람쥐" / '매우 밝음' ↔ '크게 밝음'.
- 인계 `config/game-balance.json`의 수치는 모두 인계 문서의 임시 제안(원본에 없음).

Claude 판단 (모두 제안 — 체감 후 조정)

- **시너지·대광원 없앰**: 새 기획에 없고 LP가 자원 역할을 맡는다. HUD에 HP·하트·LP·광원·등불이 들어가야 해서 게이지를 하나 줄인다.
- **문구**: 죽·처치·킬·실패는 계속 쓰지 않는다(빛은 되돌리고 구하는 것). 판이 끝나면 '패배' 대신 "오늘은 여기까지", 기본 승리 "아침이 왔어요", 완전 승리 "마을이 환해졌어요".
- **'설명 없음' 원칙 해제**: 튜토리얼 스테이지·짧은 스토리 소개·패시브 대사를 넣되 짧게, 건너뛸 수 있게(Phase 3·6).
- **자비 대상**: 답변에 '잃어버린 주민'으로 적혀 있으나, 잃어버린 주민은 빛을 맞혀야 구출되므로 원본 XMind대로 **패시브 주민**을 대상으로 한다(확인 요청). 횟수 제한 없이, 같은 주민은 다시 멀어졌다 돌아와야 다시 받는다(그 자리에서 무한히 받지 않게).
- **캐릭터**: 루미, 토리(토끼), 도토(다람쥐 — 햄스터에서 바꿈, 이름이 도토리와 어울림). 바루·몽이는 뺀다.
- **하트 재생성 무적**: 2초(깜빡임).
- **새 판 조립**: 새 씬을 따로 만들지 않고 git으로 보존한 뒤 PlayScene(키 `Play`)을 고쳐 쓴다. 개발 도구·헤드리스 스크립트가 그대로 돌아간다. 600줄 규칙을 지키도록 새 로직은 모듈로 나눈다.
- 첫 스테이지 수치는 CLAUDE.md 3절과 `src/data/game.json`·`stages.json`.

## 7. 안전한 마이그레이션 및 개발 순서

Step 0 — 안전장치·문서
1. `git init` + 첫 커밋 `구 기획 스냅샷` ✅
2. 인계 문서를 `docs/design/`으로 복사하고 결정을 반영(OPEN_QUESTIONS에 답, GAME_DESIGN 수정), 원본 PDF를 `reference/`로 복사. 수치는 `src/data/`에만(인계 `config/`는 만들지 않음)
3. CLAUDE.md 개편(우선순위 = 최근 것, 남는 지시 명시), `docs/plan/revisions.html`에 전면 개편 요약(PDF는 손대지 않음), 스킬 갱신(`doc:skill`)
4. 라이브(light-defense-game.web.app)는 옛 판 그대로, 새 판은 Firebase Hosting 미리보기 채널

Phase 1 — 핵심 판(이번 작업 범위)
1. 데이터: `game.json`(stage·player·lp·lightLevels·central·station·score), `stages.json`, 새 `enemies.json`(kind), `characters.json` 3명, `items.json` 새 5종(데이터만), `waves.json`·`equipment.json` 삭제
2. 순수 로직 + 테스트(위 6절)
3. 엔티티: 중앙 광원·등불 스테이션·개구리, 루미 손 등불 떼기
4. PlayScene 재조립: 빛 원점 루미·LP·등불 켜기·반자동 수정·피격 → HP → 하트 → 재생성·승패
5. 무대: 여러 광원 빛 마스크, 맵 전체 광도
6. UI: HUD(시간·점수·콤보 / 하트·HP·LP·광원·등불), 결과(승리·완전 승리·여기까지), 홈 '게임하기'·테스트는 개발 모드만, 선택 3명
7. 검증(헤드리스·autoplay) → git 커밋 → 미리보기 채널 배포 → 보고 후 대기

Phase 2 — 광도·등불·맵: 광도 모델 완성, 등불 여러 개·전체 버프, 지역 3구획, 강·다리·울타리·건물, 풀숲 시간 제한, 지역별 아이템·적 출현
Phase 3 — 적 분류: 호스틸 3종·잃어버린 주민 3종·패시브 3종, 빛 반응, 필살기, 자비·분노·대사, 클라이맥스 연출
Phase 4 — 아이템 5종(시작 전 설정 + 획득, 1회 사용), 점수·콤보, 완전 승리 보상, 결과 요약
Phase 5 — 맵 3종(스테이지 테마), 스테이지 진행(등불 1→4), 토끼·다람쥐 구출·해금, 노월 보스 스테이지, 화해 장면
Phase 6 — 튜토리얼·스토리 소개, 설정(음량·스틱 좌우·휴대폰 방향), 사운드·진동, 상점 틀, 마무리, 라이브 배포

원칙: Phase마다 typecheck·test·헤드리스 캡처로 확인하고 보고한다. 새 캐릭터·적 그림은 임시 코드 그림으로 먼저 만들고 `docs/art-order.md`에 ChatGPT 주문서를 추가해 라이언 그림으로 바꾼다. 랜덤은 seed로 재현한다.
