# 게임플레이 시스템

수치 원본: `assets/data/game.json`, `items.json`, `equipment.json`, `waves.json`, `map.json`(풀숲·장애물 배치).

## 코어 루프 (한 판 = 하룻밤, 120초)

```
선택 화면에서 주인공 1 + 장착물 1 선택 (탭 두 번) → [밤 120초 시작, 루미가 빛기둥 속에서 나타남]
  ↳ 악당이 화면 가장자리 바깥에서 나와 등불지기가 든 등불을 쫓아온다
  ↳ 플레이어는 이동 스틱으로 걷고(풀숲에 숨기·장애물 돌기), 빛 스틱을 끌어 막고 싶은 방향을 겨눈 뒤 놓는다
     → 루미의 중심에서 그 방향으로 부채꼴 빛 → 악당을 되돌린다
  ↳ 맞추면 콤보 +1, 점수 배율 ↑, 시너지 게이지 ↑ → 100이면 대광원(전방위)
  ↳ 놓치면 악당이 등불에 닿아 HP를 깎고, 처음 닿을 때 콤보가 절반으로
  ↳ 시간대가 깊어질수록 악당 수·종류 ↑, 안개·달그림자, 마지막엔 노월
→ 등불 HP 0 = 게임 오버 | 120초 도달 = 클리어 → 결과 → 랭킹
```

끌고 놓는 한 동작으로 이해되는 규칙과, 콤보를 끊지 않으려는 욕심이 만드는 긴장감이 핵심이다. 평균 플레이어가 초저녁은 무난히, 한밤에서 압박을 느끼고, 새벽 전에서 절반쯤 게임 오버되도록 조정한다.

## 조작 (두 스틱, 2026-11-04 개정)

기획서의 '입력은 탭 하나 · 주인공 이동 없음 · 단일 화면'은 브롤스타즈식 두 스틱으로 대체됐다. 판단이 안 서는 조작 세부는 브롤스타즈의 공격 방식을 따른다.

| 동작 | 모바일 (기준) | PC |
|---|---|---|
| 걷기 | 왼쪽 아래 **이동 스틱**을 끄는 방향으로 | WASD·방향키 |
| 겨누기 | 오른쪽 아래 **빛 스틱**을 끄는 동안 루미 중심에서 60° 원뿔 범위가 보임. 방향 = 끄는 방향, 반지름 = 끈 거리(스틱 반지름 대비 0~1) × 최대 사거리 | 마우스 왼쪽 버튼을 누른 채 끄는 동안 원뿔이 보임. 방향 = 커서 쪽 360°, 반지름 = 루미 중심에서 커서까지 거리(최대 사거리까지). 걸으면서도 조절 |
| 방향 빛 발사 | 빛 스틱을 놓으면 그 방향·그 길이로 발사 | 마우스 버튼을 놓으면 발사 |
| 자동 조준 | 빛 스틱을 끌지 않고 짧게 탭 → 사거리 안 가장 가까운 이웃(없으면 가장 가까운 이웃)에게, 사거리 끝까지 | — |
| 취소 | 끌었다가 가운데(데드존 0.18)로 되돌려 놓기 | 루미 중심 가까이(48 안, `controls.mouseCancelRadius`)에서 놓기 |
| 전방위 빛(대광원) | 자동 발동, 별도 입력 없음 | 자동 |
| 일시정지 | 하단 ⏸ 버튼 | 버튼 또는 Esc |

- 주인공은 **등불을 손에 들고 걷는다.** 이동 속도 225(2026-11-06 개정, 150의 1.5배, 제안: 기획서에 없음), 이동 입력은 0.1초에 걸쳐 따라붙는다. 바라보는 쪽 = 걷는 방향(빛 스틱·마우스로 끄는 동안에도 그대로, 멈춰 있으면 마지막 방향), 빛을 보내는 순간(공격 동작 0.2초)에만 그 방향(2026-11-06 라이언 지시, 부드럽게 돌아감) (2026-11-06 개정).
- 스틱 판정 수치(데드존 0.18, 자동 조준 규칙, PC 취소 반경 48)는 열린 결정 8 — 휴대폰 체감 후 조정한다.
- 두 스틱은 DOM(`src/ui/Sticks.ts`, 스틱마다 pointerId 붙잡기)이고 `input:move / input:aim / input:fire` 이벤트로 게임에 보낸다. 판정 로직은 순수 TS `src/systems/movement.ts`·`aimStick.ts`(Vitest), PC 키보드·마우스는 `src/input/DesktopControls.ts`. PlayScene은 입력 장치를 모른다. (기획서의 `TapInput`은 쓰지 않는다.)
- HUD 위에서는 게임 입력이 나가지 않게 CSS `pointer-events`로 막는다. 두 스틱은 하단 띠 바로 위 양쪽 엄지 자리에 두되 화면 구석에 너무 붙이지 않는다.

## 마을·풀숲·장애물 (2026-11-04 추가)

- 마을(월드)은 **16:9 3200×1800**(2026-11-06, 처음 정사각 2400×2400과 면적 같음 — 풀숲·장애물은 크기 그대로 위치만 옮김), 시작 위치 가운데(1600, 900) (2026-11-06 개정). 카메라가 등불지기를 따라가고, 보이는 범위는 화면 방식(세로 540×960 / 가로 높이 540·폭은 화면 비율)에 따라 바뀐다.
- 배치는 `map.json` 한 파일을 그림과 판정이 함께 읽는다.
- **풀숲 8곳**: 들어가면 숨는다 — 등불지기·등불이 반투명(불투명도 0.45)해지고 빛 고임이 절반. 140 안의 이웃만 알아채고(브롤스타즈처럼 아주 가까우면 보임), 나머지는 루미를 못 보고 마을을 맴돈다 — 지금 자리에서 180~420 떨어진 마을 안 지점을 0.6배 속도로 차례로 옮겨 다닌다(2026-11-06 개정, `hide.roamSpeed·roamMin·roamMax`, 제안: 기획서에 없음). 빛을 쏘면 1초 드러난다. 수치는 열린 결정 10(제안: 기획서에 없음).
- **장애물**(바위 8·술통 4·등불 기둥 5): 등불지기는 못 지나간다(발 위치 판정, 발 판정 반지름 26 `keeper.radius`). 파닥은 날아서 무시하고, **빛은 통과한다**(열린 결정 9). 땅으로 걷는 이웃(그르르·말랑·킥킥)이 장애물을 돌아가는 것은 M2. 수치는 제안: 기획서에 없음.

## 등불 (Lantern)

- **등불지기가 손에 들고 다닌다**(2026-11-04 개정, 기획서의 `(270, 560)` 고정을 대체). 판 시작 위치는 마을 가운데(`lantern.x/y` = 1200, 1200, 제안: 기획서에 없음). 충돌 반경 48, HP `maxHp = 100`. HUD에는 **불꽃 5개**(20HP당 1개, 마지막 불꽃은 HP 비율만큼 작아짐)로 표시한다.
- 등불 HP는 **불빛의 크기**로도 표현한다: 글로우 반경 `60 + 140 * hp/maxHp`. HP 30% 이하에서는 깜빡임(초당 2회, 알파 0.85~1.0) + 화면 가장자리 잔불 주황 펄스.
- 악당이 반경 48에 닿으면 등불에 붙어 `lanternDamage`를 `damageTickSec` 간격으로 준다. **처음 닿는 순간** `combo:change`로 콤보가 절반이 된다(닿아 있는 동안 반복해서 깎지는 않는다). 빛에 밀려나거나 등불이 멀어지면(등불이 닿는 거리 × 1.25 밖, 열린 결정 8) 떨어졌다가 다시 쫓아온다.
- 등불이 맞으면 등불지기가 흰 번쩍임과 함께 이웃 반대쪽으로 14px 밀리고(장애물·마을 끝 판정) 화면이 0.12초 흔들린다(제안: 기획서에 없음).
- 자연 회복은 없다(바루 특성, 아이템, 장착물로만). 회복은 maxHp를 넘지 못한다.

## 빛 (Light) — 루미 중심 부채꼴 (2026-11-06 개정)

- 발사 시 **루미의 중심**을 꼭짓점으로(2026-11-06 개정: 등불이 아니라 루미 중심, 판정도 같은 점), 조준 방향 `angle`을 중심으로 **`fanDeg = 60°` 부채꼴**이 `expandSec = 0.25초`에 걸쳐 반지름 0 → 실제 빛 길이까지 퍼진다(알파 0.9 → 0). 부채꼴은 쏜 자리에서 퍼지고 등불지기를 따라오지 않는다.
- **실제 빛 길이 = 최대 사거리 × 끈 정도**(빛 스틱은 스틱 반지름 대비 0~1, PC는 루미~커서 거리). 짧게 탭한 자동 조준은 최대 사거리 끝까지. 최대 사거리는 캐릭터별 270~390(2026-11-06 개정, 기획서 180~260의 1.5배). 기획서의 고정 사거리를 대체한다.
- 부채꼴 안의 악당 각각에 `lightPower`만큼 HP를 깎고, 루미 반대 방향으로 `knockback = 70px`(몽이 140, 악어 0.5배) 밀어내며 `stunSec = 0.3초` 정지. 부채꼴 안의 **아이템은 획득**된다(+10점) — 아이템은 빛으로 줍는다. 빛은 장애물을 통과한다.
- 다음 발사까지 대기 `cooldownSec = 0.4초 × 캐릭터 lightCooldownMultiplier × 장착물 배율`(토리 0.8, 바람 신발 0.8, 둘 다면 0.256초). 대기 중 발사는 무시하고, 빛 스틱 테두리가 차오르며 남은 대기를 보여준다(조준 원뿔도 대기 중에는 더 옅게). 대기가 끝나면 `light:ready`.
- 60°는 조준이 조금 빗나가도 맞게 하려는 폭이고, 0.4초 대기는 연타를 막아 "어느 방향을 먼저 막을까"가 판단이 되게 하려는 것이다. 둘을 같이 조정한다.
- 빛은 등불 HP를 소모하지 않는다(남은 결정 사항).
- **대광원(시너지 발동)**: 등불에서 **전방위**(원형) 빛이 0.6초간 화면을 밝히며 모든 악당에 `lightPower × 3` 피해 + 넉백 200. 마녀에게도 적용. 발동 후 시너지 0.

## 콤보와 시너지

### 콤보 (연달아 물리침)
- 악당을 되돌리면 콤보 +1. 같은 빛 한 번으로 여러 마리가 되돌아가면 각각 +1(박쥐 떼, 슬라임 분열이 콤보 재료).
- 점수 배율: `multiplier = 1 + floor(combo / 5) * 0.5`, 최대 4.0 (콤보 30 이상).
- **콤보 감소는 두 경우 모두 "절반(소수점 버림)"**(`game.json combo.lossMode = "half"`): (a) 악당이 등불에 처음 닿았을 때, (b) 마지막 되돌림 후 `comboWindow = 2.0초` 안에 다음 되돌림이 없을 때. 0으로 초기화하지 않는다 — 한 번의 실수로 전부 잃지 않게 하되, 연속 실수는 빠르게 깎이도록. 유지 시간 초과로 절반이 된 뒤에는 타이머를 다시 2.0초로 두고, 콤보가 0이 될 때까지 반복한다. 2.0초는 초저녁 생성 간격 2.5초보다 짧아 튜닝 1순위다(열린 결정 7).
- HUD: 상단 콤보 `×{n}`(호박색)이 증가마다 1.2배로 튀었다 돌아오고, 콤보 단계마다 큰 금빛 "콤보 ×N"이 뜨며 마을 창문·등불이 하나씩 켜진다(2026-10-30 개정). 콤보 유지 남은 시간은 숫자 옆 작은 링. 줄어들 때는 숫자가 살짝 어두워진다.
- 콤보 효과음은 `sfx_light`가 콤보 수에 따라 반음씩 올라가고(12단계 후 유지), 5마다 `sfx_combo` 짧은 화음.

### 시너지 게이지 (단시간에 많이)
- 게이지 `0~100`. 되돌림 1회당 `+10.4`, 콤보 10 이상이면 `+15.6`(2026-11-06 개정: 기획서 +8/+12의 1.3배 — 차는 속도 30% 빠르게, 첫 스테이지가 어렵지 않게)(별 목걸이 +2, 별사탕 ×1.5).
- 아무 되돌림이 없으면 초당 `-4`(쉬면 빠진다 = "단시간"의 의미). 한밤 이후 연속 되돌림으로만 도달하는 게 의도.
- 100이 되면 자동으로 **대광원** 발동(수동 발동 없음). 토스트 `마을이 환해져요!`, 진동 2회, 반딧불 파티클이 흩어짐.

## 밤 시계와 웨이브 (NightClock + Spawner)

`waves.json`. 밤은 120초, 시간대는 셋.

| 시간대 | 구간 | 등장 악당(가중치) | 동시 최대 | 스폰 간격 | 특별 규칙 |
|---|---|---|---|---|---|
| `dusk` 초저녁 | 0~40초 | 파닥 6, 그르르 2, 말랑 2 | 4 (2026-11-06 개정: 6에서 30% 감소) | 3.6s → 2.6s (2026-11-06 개정: 2.5→1.8에서 빈도 30% 감소) | 처음 5초는 파닥만, 말랑은 30초부터. 첫 스테이지는 어려우면 안 된다 |
| `midnight` 한밤 | 40~90초 | 파닥 4, 그르르 2, 말랑 2, 호오 3, 킥킥 2 | 10 | 1.6s → 1.1s | 안개 15초마다 5초 |
| `predawn` 새벽 전 | 90~120초 | 파닥 4, 그르르 3, 말랑 2, 호오 3, 킥킥 3 | 12 | 1.0s 고정 | 90초에 노월 등장, 달그림자·안개 |
| `dawn` 새벽 | 120초 | — | — | — | 모든 악당 자동 되돌림(점수 없음), 클리어 |

- 스폰 간격은 구간 안에서 선형 보간. 동시 최대 수를 넘으면 대기. 스킬의 원래 240초 구성을 절반으로 줄인 것이므로 **마리 수가 부족하게 느껴지면 생성 간격을 먼저 줄인다.**
- 스폰 위치는 지금 보이는 화면(카메라 영역)의 가장자리 바로 바깥이고, 마을 안으로 자른다(2026-11-04 개정: 넓은 마을 + 카메라).
- 하이에나는 항상 3마리 묶음, 박쥐는 2~4마리 묶음(동시 최대 수에는 각각 센다).
- 시간대 전환 시 `night:phase` 이벤트 → 배경색(DUSK → NIGHT → PREDAWN)·BGM 악기 겹·토스트가 바뀐다.
- 난수는 전부 `rng.ts`(seedable). seed는 결과 화면 구석에 작게 표시(테스트·부정 방지용).

## 점수

```
되돌림 점수  = enemy.score × multiplier(combo)
아이템 획득  = +10
마녀 되돌림  = +2000 (배율 미적용)
클리어 보너스 = +1000 + 남은 등불 HP × 10
최종 점수    = 합계 (정수)
```

결과 화면: 제목·부제(버틴 시간 또는 등불 상태 · 되찾은 이웃 수), 통계 줄은 점수·최대 콤보만(버틴 시간·되찾은 이웃은 부제에 이미 있음), (노월을 되돌렸으면) `노월도 조금 깨어났어요`. 랭킹에는 사용 캐릭터·장착물도 함께 남긴다. 랭킹 정렬 키는 점수 → 버틴 시간 → 먼저 등록한 순.

## 종료 조건

- **게임 오버**: 등불 HP ≤ 0. 1.5초 동안 입력을 막고 불이 꺼지는 연출(마지막에 불씨 하나, 등불지기는 잠듦 zzz) → 결과 화면.
- **클리어**: `NightClock`이 120초 도달. 하늘 가장자리가 2초간 DAWN 색으로 밝아지며 악당이 물러남 → 결과 화면.
- 일시정지 중에는 시계·스폰·대기 모두 멈춘다(`timeScale`로 제어해서 UI 애니메이션은 살림).
- **테스트 판**(홈의 `테스트`, 2026-11-06 추가): 같은 마을·같은 조작으로 시작하되 이웃이 오지 않고 밤 시계가 흐르지 않는다. 끝이 없고 결과·랭킹도 없으며, 일시정지 → `홈으로`로 나온다. 루미가 걷는 모습 확인용(`RunState.test`, `ui:start-test`).

## 이벤트 표 (시스템 간 결합용)

HUD, 사운드, 진동, 연출은 전부 아래 이벤트를 구독한다. 게임 로직은 이벤트를 발행만 하고 연출을 모른다.

| 이벤트 | payload | 발행 시점 |
|---|---|---|
| `input:move` | `{ x, y }` (길이 0~1 벡터, 놓으면 0,0) | 이동 스틱 (2026-11-04 추가) |
| `input:aim` | `{ active, angle, power }` (power 0~1, 원뿔 반지름 = 최대 사거리 × power) | 빛 스틱을 끄는 동안 (2026-11-04 추가) |
| `input:fire` | `{ angle: number \| null, power? }` (null = 자동 조준) | 빛 스틱을 놓음 (2026-11-04 추가) |
| `light:cast` | `{ x, y, angle, range, characterId }` | 빛 발동 (x, y = 루미 중심에서 조준 방향으로 실제 빛 길이만큼 간 끝 점) |
| `light:ready` | — | 대기 끝 |
| `enemy:hit` | `{ enemy, remainingHp }` | 빛에 맞음 |
| `enemy:returned` | `{ enemyId, x, y, score, combo }` | HP 0 되돌림 |
| `combo:change` | `{ combo, multiplier, reason: 'gain' \| 'hit' \| 'timeout' }` | 증가/절반 |
| `synergy:change` | `{ value }` | 게이지 변화 |
| `synergy:burst` | — | 대광원 발동 |
| `lantern:damage` | `{ hp, maxHp, by }` | 피격 |
| `lantern:heal` | `{ hp, maxHp, by }` | 회복 |
| `item:spawn` / `item:pickup` / `item:stolen` | `{ itemId, x, y }` | 아이템 생성 / 빛으로 획득 / 킥킥이 가져감 |
| `hazard:warn` / `hazard:start` / `hazard:end` | `{ hazardId, x?, y?, radius? }` | 방해 예고 / 시작 / 끝 |
| `night:phase` | `{ phase, t }` | 시간대 전환 (40, 90, 120초) |
| `witch:spawn` / `witch:returned` | — | 노월 등장 / 되돌림 |
| `game:over` / `game:clear` | `{ result: RunResult }` | 판 종료 |
| `ui:load-progress` | `{ value }` | Preload 진행 → 스플래시 막대 (2026-11-04 추가) |
| `ui:start-test` | — | 홈의 `테스트` (2026-11-06 추가) |

## 밸런스 점검 체크리스트

수치를 바꾼 뒤 아래를 확인한다(Vitest 시뮬레이션 또는 손플레이).
- 루미 + 느림 가루로 초저녁을 HP 70 이상으로 넘길 수 있는가.
- 한밤에 아무것도 안 하면 등불이 15초 안에 꺼지는가(압박 확인).
- 박쥐 4마리 묶음을 부채꼴 한 번으로 전부 되돌릴 수 있는가(콤보 재료 보장).
- 시너지가 한 판에 1~2회 터지는가.
- 노월(위쪽)을 되돌리려 위쪽으로 빛을 보내는 동안 등불 아래쪽이 위험해지는가(리스크가 실재하는가).
