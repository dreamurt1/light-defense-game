# 세계관과 이야기 (2026-11-12 새 기획)

원본: 라이언의 XMind(`reference/light-defense-xmind-1112.pdf`) → `docs/design/GAME_DESIGN.md`. 옛 설정(태양이 잠든 반딜마을, 어둠 = 잊힘, 등불을 든 등불지기, 하룻밤 120초)은 대체되었다.

## 톤

- **차분하고 은은하되 우울하지 않게.** 플레이는 캐주얼하고 박진감 있게.
- 세계관은 짧게 전한다: 첫 플레이의 튜토리얼 스테이지(짧은 스토리 소개, 이후 건너뛰기), 패시브 주민의 한 줄 대사, 배경색·사운드. 긴 컷신·설명은 피한다(옛 '대사·튜토리얼 없음' 원칙을 2026-11-12 대체).
- 슬로건: `작은 빛으로, 마을을 되찾아요.` (옛 `탭 한 번, 빛 한 줄기. 오늘 밤도 끝까지.`는 두 스틱·로밍 게임에 맞지 않아 바꿈, 제안)

## 설정 요약

- **빛의 마을과 어둠의 마을**: 서로 다른 환경에서 사는 주민들의 영역. 빛의 마을이 발전하며 밝은 영역이 넓어지자, 공격적인 어둠의 주민들이 외곽 등불을 꺼뜨렸다. 빛을 잃은 빛의 주민 일부는 본래 모습을 잃고 어둠의 무리에 적응했다(= 잃어버린 주민).
- **중앙 광원**: 마을의 심장이자 수호 토템. 어둠의 습격으로 금이 갔다. 꺼지면 마을이 함락된다(최후 보루).
- **루미**: 소중한 친구들(토끼 토리, 다람쥐 도토)을 잃은 고양이. 중앙 광원에 마을을 지켜 달라고 빌다가, 흩어진 광원의 파편에서 빛을 전하고 쏘는 힘을 얻었다(가장 순수한 마음을 가져서). 등불을 들지 않고 스스로 빛을 쏜다.
- **등불 스테이션**: 마을 외곽의 꺼진 등불들. 빛을 맞히면 다시 켜지고, 모두 켜지면 마을 전체가 서서히 밝아진다.
- **어둠의 주민**: 모두가 적은 아니다. 호스틸은 빛의 영역을 침략하고 중앙 광원을 끄려 하고, 패시브는 전투 의지 없이 어둠의 영역을 배회한다 — 빛에 상반되는 존재를 무조건 물리치는 것이 정답이 아니라는 입체적인 세계.
- **마녀 노월(가칭)**: 어둠의 주민들이 빛 때문에 터전을 잃는 것을 막고 싶었던 보스. 호스틸 세력의 대표.
- **메시지**: 싸움을 원하는 무리가 있듯 갈등은 한 번에 풀리지 않는다. 서로를 존중하는 무리가 조금씩 늘어 이해와 공존으로 나아간다(화해 장면은 보스전·랜덤 이벤트 후보 — Phase 5).

## 의문과 보완 (XMind의 답)

| 질문 | 답 |
|---|---|
| 호스틸은 왜 위협이 되는 빛을 무릅쓰고 침입하나? | 빛의 영역이 넓어져 자기 터전을 잃으니까. 빛에 닿으면 움찔하고, 눈을 가리고, 어둠에서보다 느려지고, 일부는 등불을 피한다 |
| 빛의 주민은 어떻게 빼앗겼나? | 외곽 등불이 꺼지며 빛을 잃은 주민이 점차 본래 모습을 잃고 어둠의 무리에 적응했다 |
| 루미가 영웅이 되는 이유는? | 어둠의 무리에게 잃은 친구를 구하려고 위험을 무릅쓰고 외곽으로 나선다 |
| 왜 빛을 쏠 수 있나? | 중앙 광원에 금이 갈 때 흩어진 빛의 파편으로 힘을 얻었다 |
| 플레이어블 추가? | 아니오. 친구 둘(토리·도토)을 하나씩 되찾으면 플레이 가능 |
| 중앙만 지키는 플레이는? | 외곽 등불을 켜면 맵 전체 광도 버프, 아이템도 등불·외곽에서 주로 나와 나가게 만든다 |
| 패시브를 공격하면 이득이 없다? | 길을 막거나 아이템 자리에 머무는 방해 요소라, 무찌를지 그냥 지나갈지 고르게 한다(지나가면 자비 점수, 여러 번 공격하면 호스틸이 늘어남) |

## 한 스테이지의 흐름

1. **시작**: 첫 화면이 중앙 광원과 루미를 비춘다. 루미가 빛기둥 속에 나타난다.
2. **0~70%**: 어두운 마을을 로밍하며 박쥐를 돌려보내고 잃어버린 주민을 구한다. 외곽 등불을 켜러 갈지, 중앙을 지킬지 고른다. 마을은 서서히 밝아진다.
3. **70%~ 클라이맥스**: 적이 크게 늘고 광도 변화 폭이 커진다.
4. **아침**: 마을 전체가 켜지고 남은 적이 스스로 물러난다. 기본 승리 "아침이 왔어요", 광원·등불이 모두 밝으면 "마을이 환해졌어요".
5. **여기까지**: 하트를 다 쓰거나 중앙 광원이 꺼지면 빛이 사그라들고 루미가 잠든다. "오늘은 여기까지".

### 결과 — 오늘 전투 개요
| 결과 | 제목 / 부제 |
|---|---|
| 기본 승리 | 아침이 왔어요 / 중앙 광원을 지켰어요 · 남은 하트 {n}개 |
| 완전 승리 | 마을이 환해졌어요 / 중앙 광원과 등불이 모두 밝게 빛나요 · 점수 ×2.5 |
| 하트 소진 | 오늘은 여기까지 / 버틴 시간 {mm:ss} · 구출한 주민 {n}명 |
| 중앙 광원 꺼짐 | 오늘은 여기까지 / 중앙 광원이 잠들었어요 · 버틴 시간 {mm:ss} |
| 통계 줄 | 오늘 점수 · 최대 콤보 · 구출한 주민 · 돌려보낸 어둠의 주민 · 켠 등불 |
| 버튼 | 다시 한 번 / 홈으로 / 지난 밤들에 남기기 (등록 후: 지난 밤들에 남겼어요 · {n}위) |

### 톤 규칙
- 짧게(한 줄 20자 안팎), 존댓말 "~요".
- 금지어: `죽, 처치, 킬, 실패` (게임 오버도 '패배' 대신 "오늘은 여기까지"). 처리한 적은 "구출한 주민"(잃어버린 주민) / "돌려보낸 어둠의 주민"(호스틸).
