# 비주얼과 사운드

## 전체 콘셉트

"어두운 밤, 따뜻한 빛."
- 배경은 차갑고 어둡게, 빛과 주인공만 따뜻한 색으로 둔다. 그러면 화면에서 눈이 가야 할 곳이 저절로 정해진다.
- 귀엽지만 유치하지 않게: 작은 동물들이 사는 아늑한 밤 마을 + OneShot의 조용한 정서.

**아트 디렉션** = `reference/ChatGPT-Images/`의 레퍼런스 이미지(완성 UI 규격이 아니라 분위기 레퍼런스).
- 공간감과 디자인의 1순위 기준은 「달빛 숲의 등불지기 고양이.png」다.
- 평평한 톱다운 맵·고른 벽돌 격자(Super Animal Royale 결)는 피한다. 일반 판타지 디펜스나 쿼터뷰 RPG처럼 보이면 안 된다 — 아늑하고 독자적인 인디 게임의 결.
- 그 밖의 레퍼런스: Stray·OneShot(분위기·색감), Cult of the Lamb(2.5D·지면 재질).
- 화면 레이아웃은 `light_defense_ui_screen_sheet.png`, 에셋 형태는 `light_defense_sprite_asset_reference_sheet.png`를 참고한다. 시트와 기획이 다른 항목의 결정은 프로젝트의 `docs/reference-crosscheck.md`에 있다.

감정의 중심은 파괴감이 아니라 **빛이 닿을 때의 따뜻함과 콤보의 손맛**이다: 부채꼴 안의 반짝이 별, 구출·돌려보냄 순간의 별 조각, 콤보 단계마다 큰 금빛 "콤보 ×N"과 마을 불빛.

## 화면과 2.5D 연출 규칙

- 화면은 짧은 변 540 기준이다. 세로 540×960, 가로는 높이 540·폭 720~1280. 물체 크기는 그대로이고 보는 프레임만 바뀐다.
- 마을(월드)은 16:9 3200×1800, 가운데에 중앙 광원(1600, 900)이 있다.
- 시점은 약간 기울인 톱다운(2.5D)이다. 실제 3D는 쓰지 않고 다음 규칙으로 깊이를 만든다.
  - 모든 캐릭터·아이템은 발밑에 타원 그림자가 있다.
  - `setDepth(y)`: y가 클수록 앞.
  - 깡충 뛰기처럼 튀는 연출은 스프라이트 y 오프셋으로 하고, 그림자는 제자리에 둔다.
  - 등불지기가 오두막·담·기둥·광원 뒤에 있으면 그 물체가 반투명해진다(`entities/Occluders.ts`).
- 무대: 작은 동물들이 사는 밤의 마을.
  - 크고 불규칙한 판석 광장(금·이끼).
  - 벽면과 지붕 경사가 보이는 오두막, 따뜻하게 켜진 창문.
  - 울타리·술통·깃발 줄·큰 나무뿌리·어두운 청록 풀숲·라벤더 꽃·반딧불.
  - 동쪽 강과 다리.
- 어두운 마을과 켜진 마을 두 겹을 빛 마스크로 드러낸다. 빛 고임: 루미 주변(LP 비례 × 구획 시야), 빛의 마을(중앙 광원 둘레를 은은히), 중앙 광원(광도 비례), 켜진 등불, 랜덤 이벤트의 반딧불 무리.
- 구획 막(2026-11-18): 중앙 광원에서 멀수록 짙어지는 어두운 막이 어두운 마을 위에 깔린다(어둠의 마을 테마일수록 진함). 빛 고임이 닿은 곳은 막 위로 드러난다.
- 중앙 광원 = 세 단 돌 제단 + 금 간 큰 결정(176×236). 등불 스테이션은 큼직하게. 광원·등불의 광도(= HP) 게이지는 그림 위에 둔다(`entities/SourceGauge.ts`).
- **조준 원뿔**: 빛 스틱(PC는 마우스)을 끄는 동안 루미 중심에서 60° 원뿔을 **바닥에** 편다(캐릭터·소품 아래).
  - 면은 밝은 노랑 50%, 선 없음.
  - 끈 거리에 따라 반지름 길이만 바뀐다. 빛 대기 중이면 더 옅게.
  - 반자동으로 누르고 있는 동안은 대상 적을 가리킨다.
- **발사**: 부채꼴이 0.25초 동안 쏜 자리에서 퍼지고(알파 0.9 → 0), 별이 원뿔 안으로 날아간다.
- 파티클: 등불 둘레 반딧불, 구출·돌려보냄 때 별 조각. 동시 파티클 상한을 둔다.
- 깜빡임은 초당 3회 이하(무적 맥박 2.5회, 노란 화살표 1.6초 주기).

## 캐릭터 그림

### 루미
- 주황 스카프를 두른 초록 눈의 검은 고양이. **등불을 들지 않는다.**
- 정지·걷기 모습은 ChatGPT 8방향 팩(`reference/Lumi_8_Direction_Pack/`)이 기준이다.
  - 정지: 256×256 앉은 자세 8장.
  - 걷기: 8방향 × 4프레임, 9fps.
- 게임 안 한 칸 128×128, 몸 키 약 101, 발 판정 반지름 26.
- 바라보는 쪽 = 걷는 방향이다. 멈추면 마지막 방향, 빛을 보내는 순간(0.2초)만 그 방향으로 부드럽게 돈다.
- 공격·피격·부활은 지금 보이는 팩 그림 위에 동작 효과를 더한다(`systems/keeperMotion.ts`).
  - 공격 = 조준 쪽으로 웅크렸다 내밀기 0.2초.
  - 피격 = 맞은 반대쪽으로 확 젖혀지며 움츠림 0.38초 + 흰 번쩍임 뒤 붉게 0.15초 + 14px 밀림 + 화면 0.12초 흔들림.
  - 부활 = 빛기둥 속에서 정면 정지 모습.
- 하트를 잃으면 잠든 모습(zzz). 판이 끝나면 정면 정지 자세. 일시정지 중엔 애니메이션도 멈춘다.
- 초상 = 대기 팩 45°(`lumi_idle_045_front_right.png`).

## 그림 규격과 대체 그림

그림은 분리된 투명 PNG 스프라이트 시트로 다룬다.

| 단계 | 위치 | 설명 |
|---|---|---|
| 의뢰 | `hand-offs/chatgpt-<주제>-YY-MMDD-HHMM/` → 바탕화면 전달 폴더 | 의뢰서(한국어 설명 + 영문 프롬프트)·안내 그림·기준 사실서. 프로젝트 스킬 `ld-chatgpt-order` |
| 받기 | `reference/<Pack>/` | 규격·기준과 대조(크기·발끝·방향·리본 귀·눈 색·눈 겹침). 프로젝트 스킬 `ld-art-intake`, `scripts/art-check.mjs` |
| 원본 | `art-src/<분류>/<키>.png` | 게임에 넣을 원본 |
| 게임용 시트 | `npm run assets` → `public/assets/<분류>/` + `manifest.json` | 규격은 `src/art/registry.ts`, 배경 지우기 `cutout.ts`. `PreloadScene`이 매니페스트로 불러온다 |
| 대체 그림 | `src/art/*`(Canvas 2D 코드) | ChatGPT 그림이 아직 없는 키에 쓰인다. 미리보기는 dev 서버의 `/assets.html` |

## UI / HUD

- 메뉴와 HUD는 캔버스 위 HTML/CSS 오버레이다.
  - 크기는 UI 단위 `--u`(세로 = 폭/540, 가로 = 높이/540)와 컨테이너 쿼리로 게임 박스에 비례시킨다.
  - UI 재질은 `src/ui/finish.css` 한 곳에 모은다.
  - HUD는 값이 바뀔 때만 갱신한다.
- **버튼**
  - 알약형: 주요 = 호박 채움 + 남색 글자, 보조 = 어두운 유리 + 밝은 테두리. 최소 48px.
  - **둥근 배지·아이콘 규칙**(2026-11-13 라이언): 동그란 버튼·표시기는 모두 같은 결로 만든다.
    1. 남색 유리 원(#34396C → #14152E) + 얇은 밝은 테두리.
    2. 굵고 끝이 둥근 선 아이콘(연한 종이색).
    3. 켜짐·준비 = 호박 사탕 채움 + 남색 아이콘.
    4. 놓으면 부드럽게 제자리(cubic-bezier(0.16, 1, 0.3, 1)).
    - 기준 구현은 `.pull-refresh`·`refreshIcon`·`.icon-button`.
- **위 HUD**(safe area 아래, 터치 요소 없음): 달 · `밤 mm:ss` · 밤 진행 바(한밤중·클라이맥스 눈금) · 점수 · 콤보 `×{n}` + 유지 시간 링. 노월이 나오면 그 아래 라벤더 보스 체력바.
- **아래 HUD**: 하트 3개 · **HP** 막대 · **LP** 막대(글자 'HP'·'LP') · 중앙 광원 막대(결정 아이콘) · 켠 등불 수 · 아이템 칸 2개 · 일시정지.
- **판 위 표시(월드, HUD 아님 — 2026-11-24)**: 적 빛 게이지 = 맞은 적 발밑에 잠깐 36×4 둥근 막대(바탕 NIGHT 0.6 · 채움 AMBER, 받은 빛만큼 차오름, 1.2초 + 0.3초 페이드, 호스틸·잃어버린 주민만). 마지막 하트 위험 링 = 하트 1 + HP ≤ 50%에 루미 발밑 EMBER 링(반지름 34·선 2px·0.35~0.7 숨쉬기 1.2초). 둘 다 한 번 구운 그림을 쓰고 값이 바뀔 때만 자르기·불투명도를 바꾼다. 주인공 머리 위 HP 막대는 두지 않는다.
- **화살표**: 화면 밖 적 = 라벤더. 꺼진 등불·위험한 광원·빛을 잃은 친구 = 노란 화살표(화면 밖이면 가장자리, 화면 안이면 그 위).
- **두 스틱**: 아래 양쪽 엄지 자리. 왼쪽 이동, 오른쪽 빛. 빛 대기 중에는 빛 스틱 테두리가 차오른다.
- 토스트는 위 HUD 바로 아래에 1.5초 떠오르며 사라진다.
- **가로 화면**
  - 휴대폰은 기기 방향을 따른다(판 중에 돌리면 일시정지). PC는 가로가 기본이고 설정에서 세로로 바꿀 수 있다.
  - 17:9보다 좁은 가로(태블릿·PC 16:9 창)는 판을 바닥 가운데로, 두 스틱은 그 위로 둔다.
  - 폰 가로는 두 스틱을 엄지가 편하게 안쪽으로 둔다.

## 사운드 (`src/audio/*`, Web Audio 합성 + 녹음 음원 자리)

### 배경음 (`Bgm.ts`)
D장조의 은은한 곡이다(OneShot 분위기 참고, 오르골 선율은 새로 지음). 코드 진행: Dmaj9 → A/C# → Bm7 → F#m7 → Gmaj7 → D/F# → Em7 → A7.

| 모드 | 장면 | BPM |
|---|---|---|
| `menu` | 홈·선택·지난 밤들 | 60 |
| `play` | 판 | 72 |
| `climax` | 새벽 전(70%~) | 92 |
| `calm` | 결과(아침·오늘은 여기까지) | 56 |

일시정지 중엔 배경음을 낮춘다.

### 효과음 (`Sound.ts`, 이벤트 → 소리)

| 이벤트 | 소리 |
|---|---|
| `light:cast` | 빛 보내는 소리 |
| `enemy:hit` · `enemy:returned` | 적중 · 구출/돌려보냄 |
| `combo:change` | 콤보 단계 |
| `player:hurt` · `player:down` · `player:respawn` | 맞음 · 하트를 잃음 · 부활 |
| `central:hit` | (아직 소리 없음 — 제안: 낮은 결정 울림) |
| `station:lit` | 등불 켜짐(모두 켜지면 더 크게) |
| `item:pickup` · `item:use` | 아이템 줍기 · 쓰기 |
| `mercy:gain` · `passive:upset` | 자비 · 분노 |
| `friend:rescued` | 친구 구출 |
| `witch:spawn` · `boss:attack` · `witch:returned` | 노월 등장 · 소환/구슬 · 진정 |
| `stealth:exposed` | 풀숲에서 들킴(바스락) |
| `game:clear` · `game:over` | 아침 · 오늘은 여기까지 |

- 소리는 첫 입력 이후에만 난다(`AudioContext.resume()`).
- 설정: 배경음악·효과음 = 켜기 스위치 + 음량 슬라이더(0~100, 5씩, 기본 100), 진동 = 켜기(`localStorage`). 슬라이더 값은 귀 곡선(제곱)으로 버스 음량이 된다(반 = 약 −12dB, 제안). 효과음 슬라이더를 놓으면 줍기 소리를 한 번 들려준다(2026-11-19).
- **녹음 음원**(2026-11-19, `audio/Recorded.ts`): `public/audio/manifest.json`에 `bgm.{menu|play|climax|calm}`·`sfx.{Sfx 이름}` 파일을 적으면 그 소리를 합성 대신 쓴다(배경음은 반복·모드가 바뀌면 엇갈려 바꿈, 기본 음량 0.5 제안). 목록이 비었거나 못 읽으면 합성 그대로. 지금 목록은 비어 있다.
