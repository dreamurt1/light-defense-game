## 전체 콘셉트

"어두운 밤, 따뜻한 빛." 배경은 차갑고 어둡게, 빛과 주인공만 따뜻한 색으로 두어 화면에서 눈이 가야 할 곳이 저절로 정해지도록 한다. 귀엽지만 유치하지 않게 — 작은 동물들이 사는 아늑한 밤 마을 + OneShot의 조용한 정서.

**아트 디렉션 = `reference/ChatGPT-Images/`의 레퍼런스 이미지**(2026-10-30 개정, 이전 비주얼 방향 '겹겹 종이 라이트박스'를 대체). 이미지는 완성 UI 규격이 아니라 아트 디렉션과 플레이 분위기를 전하는 콘셉트 레퍼런스다.

- **공간감과 디자인의 1순위 기준은 「달빛 숲의 등불지기 고양이.png」**. 평평한 톱다운 맵·고른 벽돌 격자처럼 Super Animal Royale을 떠올리게 하는 결은 피한다. 일반적인 판타지 디펜스나 쿼터뷰 RPG처럼 보이면 안 된다 — 아늑하고 독자적인 인디 게임의 결.
- 화면 레이아웃은 `light_defense_ui_screen_sheet.png`, 에셋 형태는 `light_defense_sprite_asset_reference_sheet.png`를 참고한다. 캐릭터 설정·게임 규칙·UI 구성·색상 코드는 기획서가 최우선이고, 시트와 다른 항목의 결정은 프로젝트의 `docs/reference-crosscheck.md`에 있다.
- 감정의 중심은 파괴감이 아니라 **빛이 닿을 때의 따뜻함과 콤보의 손맛**: 부채꼴 안의 반짝이 별, 되돌림 순간의 별 조각, 콤보 단계마다 큰 금빛 "콤보 ×N"과 마을 창문·등불이 하나씩 켜짐.

## 화면과 2.5D 연출 규칙

- 화면(뷰포트)은 세로 540×960 / 가로 높이 540·폭은 화면 비율 720~1280(짧은 변 540 고정 = 물체 크기는 그대로, 보는 프레임만 바뀜, 2026-11-06). 마을(월드)은 **16:9 3200×1800**(2026-11-06, 처음 정사각 2400×2400과 면적 같음 — 풀숲·장애물은 크기 그대로 위치만 옮김), 시작 위치 가운데(1600, 900) (2026-11-06 개정).
- 카메라는 약간 기울인 시점의 톱다운(2.5D). 실제 3D는 쓰지 않고 다음 규칙으로 깊이를 만든다.
  - 모든 캐릭터·아이템은 **발밑 타원 그림자**(너비 = 스프라이트 폭 0.8, 높이 0.3, 알파 0.35).
  - `setDepth(y)`로 y가 클수록 앞. 등불은 등불지기 손에 들려 깊이가 등불지기를 따르고, 글로우는 바닥에 깐다.
  - 튀는 연출(슬라임 분열, 킥킥 돌진)은 스프라이트 y 오프셋으로, 그림자는 제자리에 두어 높이감을 낸다.
- 무대(2026-10-30 개정, 기획서의 '언덕 풀밭 타일'을 대체): 작은 동물들이 사는 밤의 마을. 살짝 기울인 시점의 크고 불규칙한 판석 광장(금·이끼), 벽면과 지붕 경사가 보이는 집·창문이 따뜻하게 켜진 작은 집·처마 등불·툇마루·울타리·술통·깃발 줄·큰 나무뿌리·어두운 청록 풀숲·잎사귀와 라벤더 꽃, 반딧불. 먼 쪽이 어두운 깊이감, 등불마다 고이는 빛. 마을 둘레는 위쪽 집 줄, 옆·아래 덤불 띠.
- 대비: 어두운 남색 바탕 + 따뜻한 호박빛. 빛이 닿은 곳만 따뜻하게 켜진다(어두운 마을 / 켜진 마을 두 겹을 빛 마스크로 드러냄).
- **조준 원뿔**(2026-11-06 개정): 빛 스틱(PC는 마우스)을 끄는 동안 루미의 중심에서 60° 원뿔을 **바닥에**(루미·이웃·소품 아래) 편다. 면은 밝은 노랑 50%, 선 없음. 끈 거리에 따라 **반지름 길이만** 바뀌고 모양·각도는 그대로(원뿔을 통째로 늘이지 않는다). 빛이 대기 중이면 같은 노랑을 더 옅게(제안: 기획서에 없음). 독립 벡터 그래픽이다.
- **발사**: 부채꼴이 0.25초 동안 쏜 자리에서 퍼지고(알파 0.9 → 0), 별이 원뿔 안으로 날아간다(LUMI 시트 VFX). **대광원**은 원형(벡터)이 등불에서 퍼진다. 등불 글로우는 라디얼 그라디언트 텍스처 1장을 스케일로 조절.
- 파티클: 등불 주변 반딧불(작은 호박색 점, 느리게 떠다님), 되돌림 시 원래 색 파티클 6~10개와 별 조각. 모바일 60fps 우선이므로 동시 파티클 상한을 둔다.
- 플래시(대광원)는 0.6초, 초당 3회 넘는 깜빡임 금지.

### 루미의 모습 (2026-11-04 전면 재구성, 2026-11-06 개정)

- 루미는 주황 스카프를 두른 초록 눈의 검은 고양이. 기준은 `reference/LUMI-sprites` 캐릭터 시트(턴어라운드·애니메이션 표 최우선, 이동 모습은 '게임 내 연출 예시', 스틱은 '조작 UI')이고, **정지·걷기 모습은 ChatGPT 8방향 팩**(`reference/Lumi_8_Direction_Pack/`)이 기준이다(2026-11-06). 시트의 턴어라운드·걷기·공격·피격 그림은 잘라 두기만 한다.
  - 정지: `Lumi_Idle_8D_Pack`(256×256 앉은 자세 8장, 방향은 팩 `manifest.json`의 각도).
  - 걷기: `Lumi_Walk_8D_4Frames_Pack`(8방향 × 4프레임, 네 발 걸음, 9fps, 같은 방향의 정지 모습과 키를 맞춤). 이동 속도가 225로 빨라지면서 걷기 동작도 같은 비율로 빨라졌다.
- 게임 안 크기 = 그림 한 칸 **128 × 128**(2026-11-06 개정, 이전 80; 몸 키 약 101, 발 판정 반지름 26). 수치는 제안: 기획서에 없음.
- 바라보는 쪽 = 걷는 방향(빛 스틱·마우스로 끄는 동안에도 그대로, 멈춰 있으면 마지막 방향), 빛을 보내는 순간(공격 동작 0.2초)에만 그 방향(2026-11-06 라이언 지시, 부드럽게 돌아감) (2026-11-06 개정). 등불은 시트에 없으므로 손에 든 등불을 방향별로 겹쳐 그린다.
- 공격·피격·부활은 그림을 바꾸지 않고 **지금 보이는 팩 그림 위에 동작 효과**를 더한다(2026-11-06, 시트의 작은 그림은 128 칸에서 깨져 보임): 공격 = 조준 쪽으로 돌아 웅크렸다 내밀기 0.2초, 피격 = 움찔·흔들림 0.3초 + 흰 번쩍임·14px 밀림·화면 0.12초 흔들림, 부활(새 밤 시작) = 빛기둥 속에서 정면 정지 모습이 나타남 0.42초. ChatGPT 공격·피격 팩이 오면 그 그림으로 바꾼다.
- 넉아웃(등불이 꺼질 때 잠듦, zzz)만 시트의 잠든 그림을 쓴다. 기절은 보관.
- 선택·홈 프로필·상점 스킨 칸의 루미 초상 = 대기 팩의 `lumi_idle_045_front_right.png`(2026-11-06).

## 그림 규격과 대체 그림 (2026-11-04 개정)

기획서의 'Phaser Graphics 단순 도형 플레이스홀더'는 쓰지 않는다. 그림은 분리된 투명 PNG 스프라이트 시트로 다룬다.

| 단계 | 위치 | 설명 |
|---|---|---|
| 그림 주문 | `docs/art-order.md` | 에셋별 ChatGPT 프롬프트·크기·포즈. 그림은 라이언이 ChatGPT로 생성한다 |
| 원본 그림 | `art-src/<분류>/<키>.png` | 포즈 여러 개는 한 장에 나란히, 또는 `<키>.<포즈>.png` |
| 가져오기 | `npm run art:import` (= `npm run assets`) | 배경 제거·잘라 내기·크기 통일·프레임 배치. 규격은 `src/art/registry.ts`, 배경 지우기·포즈 나누기는 `src/art/cutout.ts` |
| 게임용 시트 | `public/assets/<characters·enemies·objects·effects·backgrounds·ui>/` + `manifest.json` | 프레임 가로 정렬·크기 통일, 고해상도는 매니페스트 `res`. `PreloadScene`이 매니페스트로 불러온다 |
| 대체 그림 | `src/art/*` (Canvas 2D 코드) | ChatGPT 그림이 아직 없는 키에 쓰인다. 미리보기는 dev 서버의 `/assets.html` |

- 루미 시트는 `npm run art:lumi`가 `reference/LUMI-sprites` 시트와 8방향 팩을 `src/art/lumiSheet.ts` 좌표·팩 매니페스트대로 잘라 `art-src/lumi/`에 쓰고, `npm run art:import`가 `lumi-8dir` 시트로 묶는다.
- 홈 배경은 「달빛 숲의 등불지기 고양이.png」를 잘라 정리한 그림(`assets/backgrounds/home.webp`, HUD 띠는 잘라 냄).
- 텍스처·애니메이션 키는 `TextureKeys`·`AnimKeys` 한 곳에서 관리한다.

## UI / HUD (세로 화면)

- 메뉴와 HUD는 캔버스 위 **HTML/CSS 오버레이**다(2026-10-28 개정). 오버레이 크기는 컨테이너 쿼리 단위(`cqw`/`cqh`)로 게임 박스에 비례시키고, UI 재질(광택·테두리·결·별 장식)은 `src/ui/finish.css` 한 곳에 모은다. HUD는 매 프레임이 아니라 이벤트가 올 때만 갱신한다.
- 버튼: 알약형(모서리 반경 = 높이/2), 주요는 호박 채움 + 아이콘 + 남색 텍스트, **보조는 어두운 바탕에 밝은 테두리**(2026-10-30 개정, 기획서의 민트 테두리에서 바꿈). 누르면 1.04배 + 글로우. 최소 48×48(터치 표적 최소 44px).
- **상단 UI** (safe area 아래, 터치 요소 없음, 위 한 줄): 달 아이콘 · `밤 mm:ss` · 민트 밤 진행 바 · 점수 · 현재 콤보 `×{n}`(호박, 0이면 숨김) + 유지 시간 링. 노월이 나오면 그 아래 라벤더 보스 체력바(노월 얼굴·이름·체력).
- **플레이 영역**: 카메라가 등불지기를 따라간다. 화면 밖 이웃은 화면 가장자리의 라벤더 화살표로 알린다(제안: 기획서에 없음).
- **두 스틱**: 하단 띠 바로 위 양쪽 엄지 자리 — 왼쪽 이동 스틱, 오른쪽 빛 스틱(LUMI 시트 '조작 UI' 모양을 벡터로 다시 그림). 화면 구석에 너무 붙이지 않는다. 빛 대기 중에는 빛 스틱 테두리가 차오른다.
- **하단 UI** (단색 띠, 엄지 도달 영역): 등불 체력 **불꽃 5개**(20HP당 1개) · 시너지 게이지(새싹 아이콘, 가득 차면 호박색 펄스) · 장착물 칸(M3) · 흰 테두리 일시정지 ⏸.
- 토스트는 상단 UI 바로 아래에 1.5초, 아래에서 위로 떠오르며 사라짐.
- 시각 효과 변화: 시간대 배경 보간, 콤보 단계마다 큰 금빛 "콤보 ×N"과 마을 창문·등불이 하나씩 켜짐, 피격 시 화면 가장자리 어두워짐, 안개 시 비네트 짙어짐, 등불 HP 30% 이하 시 가장자리 잔불 주황 펄스.
- 가로 화면(2026-11-06 개정): 휴대폰은 눕히면 가로, PC는 창을 꽉 채우는 가로가 기본(설정 `가로 화면`을 끄면 가운데 9:16), 설정의 `전체 화면`(브라우저가 허락할 때). 가로 HUD는 위 띠 얇게 가운데로, 아래는 띠 없이 가운데 작은 판, 두 스틱은 양 아래 구석. 폭 ÷ 높이가 17:9보다 좁은 가로(태블릿·PC 16:9 창)는 판을 바닥 가운데 600u로, 두 스틱은 그 위로(2026-11-13). 두 스틱 가운데는 같은 수평선. 예전 가로 회전 안내는 없앴다.

## 사운드

### 배경음악
| 키 | 장면 | 느낌 | 구현 |
|---|---|---|---|
| `bgm_entry` | 엔트리·선택·결과 공용 | 느린 피아노/뮤직박스 자장가 루프, 60~70 BPM | 루프 |
| `bgm_play` | 플레이 | 같은 멜로디에 리듬, 시간대마다 악기 한 겹씩 추가 (dusk 멜로디+가벼운 리듬 / midnight +베이스·퍼커션 / predawn +긴장 스트링·마녀 모티프) | 스템 3개 동시 재생, 볼륨만 올림(2초 크로스페이드) |
| `bgm_dawn` | 클리어 연출 | 새소리 + 낮은 현악, 멜로디만 밝게 | 원샷 |

같은 템포·길이의 스템을 동시에 재생하고 볼륨만 올리면 전환이 끊기지 않는다. 임시 구현은 Web Audio 오실레이터 패드로 대체.

| 이벤트 | 키 | 느낌 | 추가 반응 |
|---|---|---|---|
| `light:cast` | `sfx_light` + `voice_<id>_light` | 부드러운 종소리, **콤보가 오를수록 반음씩 ↑**(12단계 후 유지) | — |

| `enemy:returned` | `sfx_return` | 작은 종 한 음 | `+점수` 텍스트 |
| `item:pickup` | `sfx_item` | 작은 유리 구슬 소리 | 아이콘이 HUD로 날아감 |
| `item:stolen` | `sfx_hyena_laugh` | 짧은 웃음 | — |

- 모든 소리는 `AudioBus` 한 곳에서 재생(`play(key, {pitch?, volume?})`). 파일이 없으면 `AudioBus`가 합성 비프로 폴백하고 콘솔에 한 번만 경고.
- 브라우저 자동재생 정책: 첫 포인터 입력 때 `AudioContext.resume()`.
- 설정: BGM/효과음/진동 각각 끄기, `localStorage`에 저장.

## 진동 (모바일)

`Haptics.vibrate(pattern)` → `navigator.vibrate` 지원 시만(iOS Safari 등 미지원은 조용히 건너뜀). 피격 1회(60ms), 콤보 5 배수·대광원 2회(60, 40, 60ms). 연속 진동은 100ms 안에 합쳐서 한 번만.

## 마을 분위기 (2026-11-06 개정)

- 밤이 흐를수록 켜진 마을이 전체에 드러나 점점 밝아지고, 그 속도는 점점 빨라진다: 드러나는 정도 = `brightenMax(0.55) × 진행률^brightenPower(2)`. 제안: 기획서에 없음.
- 등불이 맞으면 마을이 어두워지고 밤이 깊을수록 그 깊이가 깊다: 어두움 = `(1 − 등불 HP 비율) × (gloomBase 0.16 + gloomGrowth 0.24 × 진행률)`. HP에 묶여 있어 회복하면 그만큼 빨리 걷히고 마을이 한 번 크게 환해진다. 빛 부채꼴은 어둠 위에 그려져 어둠을 뚫고 보인다. 제안: 기획서에 없음.
- 순수 로직은 `src/systems/villageMood.ts`, 수치는 `game.json`의 `village`.
