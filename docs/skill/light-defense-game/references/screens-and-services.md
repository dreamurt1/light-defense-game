# 화면 흐름, 서버, 수익 모델

화면은 가로가 기본이고 세로도 제공한다(휴대폰은 기기 방향, PC는 설정에서 세로). 로그인 없이 바로 한 판 할 수 있게 한다.

## 화면 흐름

메뉴 화면과 HUD는 Phaser 씬이 아니라 캔버스 위 **HTML/CSS 오버레이**(프레임워크 없이 TS)다.
- Phaser는 `BootScene → PreloadScene → PlayScene`만 돈다.
- 화면 이동은 `src/ui/Router.ts`가 맡는다. `#ui[data-screen]`과 `<html data-screen>`을 바꾼다.
- 씬 ↔ DOM UI는 `src/core/events.ts` 이벤트로만 주고받는다.

```
index.html 스플래시 → Boot → Preload ─(ui:load-progress)→ 스플래시가 사라짐
                                         ↓
   지난 밤들 · 상점 · 튜토리얼 · 테스트 · ⚙  ⇄  홈
                          ↓ 밤 나들이 시작 (저장된 런이 있으면 위에 '이어서 하기 (밤 n)')
              (처음이면) 이야기 카드 6장(마을 → 두 목소리 → 광원이 꺼진 밤 → 친구를 잃음 → 파편 → 아침) → 튜토리얼 판 '처음 밤'
              (마친 뒤엔) 선택: 등불지기 3칸 + 챙겨 갈 아이템 + 안내 '오늘 밤 나들이' → 빛을 밝혀요
                                         ↓
                 밤 n: PlayScene + HUD·두 스틱  ⇄  일시정지 '잠시 쉬어요'
                    ↓ 아침(밤 승리)                         ↓ 하트 0·광원 꺼짐
       아침 화면 '밤 {n}이 밝았어요' (새 구간이면 '새 지역')      결과 '오늘은 여기까지'
          ├ 다음 밤으로 → 밤 n+1                                  ↓
          └ 집으로 → 결과 '오늘 밤들은 여기까지' → 다시 나가기 / 홈으로 / 지난 밤들에 남기기

   테스트: 고르기 창 → 트라이얼(루미·토리·도토 칸) 또는 '밤 n 체험'(1·3·6·9·10, 그 밤의 평균 빛 레벨 ★1·6·8·9·10으로 시작 — 밤 10은 토리·도토를 구한 것으로 쳐 노월 확정, 테스트 판에만, 맵 고르기) → 그 판
```

### 홈 상세 (2026-11-18, 세로는 2026-11-21)
- **세로(폰 세로·PC 세로)**: 웹 썸네일 그림 `home-thumb.webp`(라이언 — 제목 LIGHT DEFENSE와 등불 둘레 실루엣이 그림에 들어 있음). 게임의 제목 그림·한글 이름·슬로건은 보이지 않게(화면 읽기용으로만 남김). 왼쪽 나무줄기 쪽에 제목 밑부터 둥근 버튼 넷 세로 목록(지난 밤들·상점·튜토리얼·테스트), 등불 받침 바로 아래 '게임하기'. PC 세로 양옆 띠는 그 그림의 등불 쪽을 흐리게.
- **가로(PC 풀·폰 가로)**: 웹 썸네일 16:9 `home-thumb-wide.webp`(2026-11-21 — 제목·실루엣이 가운데, 양옆은 어두운 숲). 버튼을 양쪽 숲에 나눔 — 왼쪽 지난 밤들·상점 / 오른쪽 튜토리얼·테스트(가운데 높이, 키가 낮으면 나란히), 오른쪽 아래 게임하기, 위 왼쪽 프로필·오른쪽 설정. 게임의 제목 그림·한글 이름·슬로건은 세로·가로 모두 숨김(슬로건 "작은 빛으로, 밤을 지켜요."는 스플래시에 남음).
- 프로필(닉네임·고른 등불지기 초상)과 ⚙는 위 양쪽 구석.
- 처음 유저의 '게임하기' = 이야기 카드 → 튜토리얼 판(건너뛸 수 없음). '튜토리얼' 버튼은 언제든 간추린 이야기부터 다시 한다.

### 선택 상세
- 등불지기 3칸: 루미·토리·도토. 큰 초상 + 이전·다음 화살표 + 이름·한 줄 소개·특성.
- 잠긴 친구는 컨셉 그림(`reference/<Tori|Doto>_8_Direction_Pack/…_Concept_Introduce/`)의 실루엣을 짙은 면색으로(`portrait-<id>-shade`, `src/art/lockedShade.ts`) + 물음표 + 자물쇠(2026-11-20). 빛을 잃은 모습(`portrait-<id>-lost`)은 판 안·이야기 카드에만. "잃어버린 친구예요. 구출하면 함께해요".
- 안내 칸(2026-11-23, 옛 스테이지 4칸 대신): "오늘 밤 나들이 — 밤 1 · 빛의 마을부터 시작해요. 아침마다 다음 밤으로 갈지, 집으로 돌아갈지 고를 수 있어요. 하트 3개는 밤들 사이에 이어져요."
- **챙겨 갈 아이템** 4칸(2026-11-18): 빛의 부적은 늘 함께, 하나 더 고른다. 잠긴 칸을 누르면 "밤 4를 지나면 별 목걸이가 열려요"(`Progress.bestNight`). 아래 줄 "빛의 부적과 반딧불 병을 챙겨 가요". 가로 화면은 제목·안내 줄을 접고 아이콘만.
- 시작 버튼 '빛을 밝혀요'(잠기면 '아직 잠겨 있어요').

### 테스트 (2026-11-14, 2026-11-18)
- 고르기 창: 트라이얼 줄(루미·토리·도토 칸 — 누른 등불지기로 바로 시작, 잠긴 친구도 됨) + 튜토리얼 + '밤 n 체험'(1·3·6·9·10, 그 밤의 평균 빛 레벨 ★1·6·8·9·10으로 시작 — 밤 10은 토리·도토를 구한 것으로 쳐 노월 확정, 테스트 판에만 — 그 밤의 규칙, 맵 고르기, 2026-11-23).
- 고른 등불지기는 그 테스트 판에서만 쓴다(`RunState.trialCharacterId`). 선택 화면의 등불지기는 그대로다.
- 테스트 판은 진행·지난 밤들에 남지 않는다. 결과에 "테스트 판이라 진행과 지난 밤들에는 남지 않아요".

### 뒤로가기·새로고침 (`ui/HistoryNav.ts`, `ui/PullRefresh.ts`, `ui/Router.ts`)
- **당겨서 새로고침**: 직접 만든 몸짓이다. 판 밖에서 아래로 120px 넘게 끌었다 놓는다.
- **뒤로·앞으로가기**: 메뉴 화면을 하나씩 방문 기록으로 둔다.
  - 게임 화면은 기록에 넣지 않는다(앞으로가기로 게임에 들어갈 수 없음).
  - 이야기·설정·테스트 창은 뒤로가기로 창만 닫힌다.
  - 결과 화면에서는 판에 들어오기 전 화면으로 간다.
  - 맨 처음 기록에서는 "한 번 더 누르면 나가요".
- **판 중**(2026-11-24 라이언, 11-25 확정): 뒤로 = 기존 일시정지 창("잠시 쉬어요")을 띄운다(모든 판 — 정식·테스트·튜토리얼), **일시정지 창이 떠 있으면 뒤로 = 창 닫기 → 판 계속**(메뉴의 '창 닫기'와 같게 — 홈은 창의 버튼으로만), 그 위에 설정 창이 열려 있으면 설정 창만 닫는다. 앞으로 = 아무 일도 안 한다. 옛 "테스트 판은 홈 + 테스트 창, 튜토리얼 판은 홈"은 없앰(일시정지 창의 홈으로).
- **화면 가장자리에서 당겨 뒤로가기**(`ui/EdgeSwipe.ts`, 2026-11-24 라이언): 왼쪽·오른쪽 가장자리 24px 안에서 시작해 안쪽으로 72px 넘게 가로로 당겼다 놓으면 위 뒤로가기와 같다(메뉴 = 앞 화면, 판 중 = 일시정지, 일시정지 창 위 = 창 닫기 → 판 계속). 태블릿·폰 모두 같은 값(화면 크기와 무관). 당기는 동안 손가락 높이에 둥근 ‹ 배지가 따라 나오고 72px 넘으면 호박빛(당겨서 새로고침 배지와 같은 결), 놓으면 부드럽게 제자리. 세로로 더 많이 움직이거나 짧으면 아무 일도 없음, 스틱 원·입력칸에서 시작한 손가락·마우스는 제외.
  - 테스트 판·튜토리얼 판은 브라우저 새로고침하면 그 판을 처음부터 다시 한다(같은 등불지기). 탭마다 sessionStorage `ld.replayRun.v1`을 쓰고, 새로고침으로 열렸을 때만 이어 간다.

### 판 단위 상태
- `src/core/RunState.ts` 객체 하나로 공유한다: characterId, stageId, seed, test, trialCharacterId → `keeperId` + 런(2026-11-23): night, hearts, level·xp, mercy·banish → `pathOf()`, carriedLitStations, prep, dustEarned, runScore, friends.
- 런 저장 `ld.run.v1`(아침마다, 런이 끝날 때 지움). 홈에 '이어서 하기 (밤 n)'. 밤 도중에 나가면 그 밤을 처음부터.
- 결과의 '다시 한 번'은 선택 화면으로 간다. 테스트 판이면 같은 스테이지를 다시 테스트로 연다.
- 아침의 '다음 밤으로'는 밤 n+1을 바로 시작한다(아침 화면을 건너뛰지 않는다). 일시정지의 '다시 한 번'은 같은 선택으로 바로 새 판을 시작한다.
- 판 시작 1.4초 뒤 토스트 "노란 화살표를 따라 꺼진 등불을 켜요"가 뜬다.

## 로그인 / 서버 (나중)

게임 로직은 클라이언트에 있다. 서버(Firebase)는 **저장·조회·검증만** 맡는다. 자체 서버는 만들지 않는다.

| 역할 | 선택 |
|---|---|
| 배포 | **Firebase Hosting** (`dist/` → https://light-defense-game.web.app), `npm run build` → `npx firebase deploy --only hosting` |
| 로그인 | Firebase Authentication(Google), 게스트는 익명 로그인 제안 |
| 랭킹·진행도 | Cloud Firestore(`asia-northeast3` 서울), `RemoteRanking`이 SDK로 직접 읽고 씀 |

- Firebase 프로젝트 id `light-defense-game`. 설정은 `.env.local`의 `VITE_FIREBASE_*`를 `import.meta.env`로 읽는다. 하드코딩하지 않고, 서비스 계정 키는 클라이언트에 넣지 않는다.
- `firestore.rules`는 온라인 랭킹을 붙이기 전까지 전부 차단이다.
- 랭킹을 온라인으로 할지는 라이언이 정한다(지금은 로컬).

**점수 제출** (`src/services/Ranking.ts`)
- 제출 필드: `{ playerId, nickname, score, survivedSec, characterId, stageId, maxCombo, seed, clientVersion, outcome: 'victory' | 'complete' | 'over', continued? }` → 결과로 `{ rank }`.
- 조회: 기간별 Top 100 `[{ rank, nickname, score, survivedSec, characterId, outcome, continued, createdAt }]`, 내 순위.
- 규칙: 일간 / 주간(월요일 0시 기준) / 전체. 정렬은 점수 → 버틴 시간 → 먼저 등록한 순.
- 클라이언트: `Ranking` 인터페이스(`submit / top / me`)에 `LocalRanking`(localStorage, 최대 100행)과 나중의 `RemoteRanking`. 오프라인·서버 오류면 로컬로 폴백한다.
- 점수 검증(온라인 랭킹 때 정할 것): 한 판 100초 동안의 이론상 최대치를 넘는 점수는 거부하고, 제출 간격을 제한한다. 보안 규칙으로 할지(무료 요금제) Cloud Functions로 할지(종량제) 정한다.

## 수익 모델 (나중) — 밸런스에 영향 없음

출시 초기에는 **기부 + 가벼운 광고**만 운영하고, 결제가 있는 상점은 리텐션이 확인된 뒤 연다. 상점은 열려 있음 — 별가루로 빛 색·꾸미기(겉모습만, 결제 없음). 캐릭터 스킨은 그림이 온 뒤.

| 모델 | 내용 | 금지 |
|---|---|---|
| 상점 | 등불지기 외형(색·모자·목도리), 빛 색(지금은 밤을 지나면 열림). 성능 영향 없음 | 능력치·아이템 판매 |
| 광고 | 오늘은 여기까지 뒤 선택형 보상 광고 1회 → 이어하기(제안: 하트 1개로). 랭킹에는 `continued` 표시 | 강제 전면 광고, 플레이 중 배너 |
| 기부 | 외부 후원 페이지. 감사 표시로 작은 배지 | — |
