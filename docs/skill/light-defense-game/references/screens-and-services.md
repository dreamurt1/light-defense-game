# 화면 흐름, 서버, 수익 모델

화면은 가로가 기본이고 세로도 제공한다(휴대폰은 기기 방향, PC는 설정에서 세로). 로그인 없이 바로 한 판 할 수 있게 한다.

## 화면 흐름

메뉴 화면과 HUD는 Phaser 씬이 아니라 캔버스 위 **HTML/CSS 오버레이**(프레임워크 없이 TS)다.
- Phaser는 `BootScene → PreloadScene → PlayScene`만 돈다.
- 화면 이동은 `src/ui/Router.ts`가 맡는다. `#ui[data-screen]`과 `<html data-screen>`을 바꾼다.
- 씬 ↔ DOM UI는 `src/core/events.ts` 이벤트로만 주고받는다.

```
index.html 스플래시 → Boot → Preload ─(ui:load-progress)→ 스플래시가 사라짐
                                         ↓
   지난 밤들 · 상점 · 튜토리얼 · 테스트 · ⚙  ⇄  홈
                                         ↓ 게임하기
              (처음이면) 이야기 카드 4장 → 튜토리얼 판 '처음 밤'
              (마친 뒤엔) 선택: 등불지기 3칸 + 밤(스테이지) 4칸 → 빛을 밝혀요
                                         ↓
                 PlayScene + HUD·두 스틱  ⇄  일시정지 '잠시 쉬어요'
                                         ↓
          결과 '오늘 전투 개요' → 다음 밤으로 / 다시 한 번 / 홈으로 / 지난 밤들에 남기기

   테스트: 고르기 창 → 트라이얼(루미·토리·도토 칸) 또는 스테이지 체험 → 그 판
```

| 화면 | 구현 | 핵심 요소 |
|---|---|---|
| 스플래시 | `index.html` + `ui/Splash.ts` | 흐린 홈 그림·일렁이는 등불·로고·슬로건·불러오기 막대. Preload 진행을 채운 뒤 최소 1.2초 후 사라짐 |
| 홈 | `ui/screens/HomeScreen.ts`, 정본 `docs/design/HOME_SCREEN.md` | 아래 '홈 상세' |
| 선택 | `SelectScreen.ts` | 아래 '선택 상세' |
| 상점 | `ShopScreen.ts` | 겉모습만. **빛 색** 5가지(호박빛 기본 · 새벽빛 · 민트빛 · 달빛 · 별빛 — 밤을 지날 때마다 하나씩, `cosmetics.json`)는 빛을 보낼 때의 별·휘두름·조준 원뿔 색을 바꾼다(`core/lightColor.ts`). 스킨은 그림이 와야 해서 '준비 중' |
| 지난 밤들 | `RankingScreen.ts` | 기간 탭(오늘·이번 주·전체), 내 순위. 지금은 이 기기에만(`LocalRanking`, `ld.ranking.v2`). 비었으면 "아직 남긴 밤이 없어요" |
| 테스트 고르기 | `ui/TestSheet.ts` | 아래 '테스트' |
| 플레이 | `PlayScene` + `ui/Hud.ts`·`Sticks.ts`·`BossBar.ts`·`Toast.ts` | HUD 위에서는 CSS `pointer-events`로 게임 입력을 막는다 |
| 일시정지 | `ui/PauseSheet.ts` | `잠시 쉬어요` — 계속 / 다시 한 번 / 홈으로 / 설정 |
| 결과 | `ui/ResultSheet.ts` | 오늘 전투 개요(`world-and-story.md` 결과 문구). 통계 = 오늘 점수·최대 콤보·구출한 주민·돌려보낸 어둠의 주민·켠 등불·자비·쓴 아이템 |
| 설정 | `ui/SettingsSheet.ts` | 배경음악·효과음(켜기 + 음량 슬라이더, 2026-11-19)·진동, 닉네임, 가로 화면(PC) / 화면 방향 자동·세로·가로(휴대폰, 2026-11-19)·전체 화면(휴대폰은 기본 켬 — 홈 화면 앱으로 열면 바로, 브라우저면 첫 탭에서 들어감(그 전까지 '화면을 한 번 누르면 전체 화면으로 바뀌어요'), 끄면 기억, 들어가면 '옆 가장자리에서 밀면 전체 화면이 풀려요', 2026-11-20), 스틱 좌우 바꾸기, 이야기 다시 보기, 처음부터 다시, 조작 설명 1장 |
| 방향 안내 | `ui/TurnHint.ts` | 휴대폰에서 방향을 고정했는데 기기가 다른 방향이면 화면을 덮고 돌려 달라고 함 + '자동으로 바꾸기'. 브라우저가 방향 잠금을 허락하면(안드로이드 전체 화면) 잠그고, 안 되면(아이폰 등) 이 안내로 대신 |

### 홈 상세 (2026-11-18, 세로는 2026-11-21)
- **세로(폰 세로·PC 세로)**: 웹 썸네일 그림 `home-thumb.webp`(라이언 — 제목 LIGHT DEFENSE와 등불 둘레 실루엣이 그림에 들어 있음). 게임의 제목 그림·한글 이름·슬로건은 보이지 않게(화면 읽기용으로만 남김). 왼쪽 나무줄기 쪽에 제목 밑부터 둥근 버튼 넷 세로 목록(지난 밤들·상점·튜토리얼·테스트), 등불 받침 바로 아래 '게임하기'. PC 세로 양옆 띠는 그 그림의 등불 쪽을 흐리게.
- **가로(PC 풀·폰 가로)**: 웹 썸네일 16:9 `home-thumb-wide.webp`(2026-11-21 — 제목·실루엣이 가운데, 양옆은 어두운 숲). 오른쪽 숲 가운데 높이에 둥근 버튼 2×2 + 게임하기, 프로필 왼쪽 아래. 게임의 제목 그림·한글 이름·슬로건은 세로·가로 모두 숨김(슬로건 "작은 빛으로, 마을을 되찾아요."는 스플래시에 남음).
- 프로필(닉네임·고른 등불지기 초상)과 ⚙는 위 양쪽 구석.
- 처음 유저의 '게임하기' = 이야기 카드 → 튜토리얼 판(건너뛸 수 없음). '튜토리얼' 버튼은 언제든 간추린 이야기부터 다시 한다.

### 선택 상세
- 등불지기 3칸: 루미·토리·도토. 큰 초상 + 이전·다음 화살표 + 이름·한 줄 소개·특성.
- 잠긴 친구는 컨셉 그림(`reference/<Tori|Doto>_8_Direction_Pack/…_Concept_Introduce/`)의 실루엣을 짙은 면색으로(`portrait-<id>-shade`, `src/art/lockedShade.ts`) + 물음표 + 자물쇠(2026-11-20). 빛을 잃은 모습(`portrait-<id>-lost`)은 판 안·이야기 카드에만. "잃어버린 친구예요. 구출하면 함께해요".
- 밤(스테이지) 4칸: 첫 번째 밤 · 경계의 밤 · 어둠의 마을 · 노월의 밤. 앞 밤을 깨면 열린다. 카드마다 등불 수·구출 친구·보스 표시.
- **챙겨 갈 아이템** 4칸(2026-11-18): 빛의 부적은 늘 함께, 하나 더 고른다. 잠긴 칸을 누르면 "경계의 밤을 지나면 별 목걸이가 열려요". 아래 줄 "빛의 부적과 반딧불 병을 챙겨 가요". 가로 화면은 제목·안내 줄을 접고 아이콘만.
- 시작 버튼 '빛을 밝혀요'(잠기면 '아직 잠겨 있어요').

### 테스트 (2026-11-14, 2026-11-18)
- 고르기 창: 트라이얼 줄(루미·토리·도토 칸 — 누른 등불지기로 바로 시작, 잠긴 친구도 됨) + 각 스테이지 체험(처음 밤·1~4, 정식 판과 같음).
- 고른 등불지기는 그 테스트 판에서만 쓴다(`RunState.trialCharacterId`). 선택 화면의 등불지기는 그대로다.
- 테스트 판은 진행·지난 밤들에 남지 않는다. 결과에 "테스트 판이라 진행과 지난 밤들에는 남지 않아요".

### 뒤로가기·새로고침 (`ui/HistoryNav.ts`, `ui/PullRefresh.ts`, `ui/Router.ts`)
- **당겨서 새로고침**: 직접 만든 몸짓이다. 판 밖에서 아래로 120px 넘게 끌었다 놓는다.
- **뒤로·앞으로가기**: 메뉴 화면을 하나씩 방문 기록으로 둔다.
  - 게임 화면은 기록에 넣지 않는다(앞으로가기로 게임에 들어갈 수 없음).
  - 이야기·설정·테스트 창은 뒤로가기로 창만 닫힌다.
  - 결과 화면에서는 판에 들어오기 전 화면으로 간다.
  - 맨 처음 기록에서는 "한 번 더 누르면 나가요".
- **판 중**: 정식 판에서는 뒤로·앞으로 모두 아무 일도 안 한다. 예외(2026-11-18):
  - 테스트 판(트라이얼·체험)에서 뒤로 → 홈 + 테스트 창.
  - 튜토리얼 판에서 뒤로 → 홈.
  - 이 두 판은 브라우저 새로고침하면 그 판을 처음부터 다시 한다(같은 등불지기). 탭마다 sessionStorage `ld.replayRun.v1`을 쓰고, 새로고침으로 열렸을 때만 이어 간다.

### 판 단위 상태
- `src/core/RunState.ts` 객체 하나로 공유한다: characterId, stageId, seed, test, trialCharacterId → `keeperId`.
- 결과의 '다시 한 번'은 선택 화면으로 간다. 테스트 판이면 같은 스테이지를 다시 테스트로 연다.
- 결과의 '다음 밤으로'는 다음 스테이지로 간다. 일시정지의 '다시 한 번'은 같은 선택으로 바로 새 판을 시작한다.
- 판 시작 1.4초 뒤 토스트 "노란 화살표를 따라 꺼진 등불을 켜요"가 뜬다.

## 로그인 / 서버 (나중)

게임 로직은 클라이언트에 있다. 서버(Firebase)는 **저장·조회·검증만** 맡는다. 자체 서버는 만들지 않는다.

| 역할 | 선택 |
|---|---|
| 배포 | **Firebase Hosting** (`dist/` → https://light-defense-game.web.app), `npm run build` → `npx firebase deploy --only hosting` |
| 로그인 | Firebase Authentication(Google), 게스트는 익명 로그인 제안 |
| 랭킹·진행도 | Cloud Firestore(`asia-northeast3` 서울), `RemoteRanking`이 SDK로 직접 읽고 씀 |

- Firebase 프로젝트 id `light-defense-game`. 설정은 `.env.local`의 `VITE_FIREBASE_*`를 `import.meta.env`로 읽는다. 하드코딩하지 않고, 서비스 계정 키는 클라이언트에 넣지 않는다.
- `firestore.rules`는 온라인 랭킹을 붙이기 전까지 전부 차단이다.
- 랭킹을 온라인으로 할지는 라이언이 정한다(지금은 로컬).

**점수 제출** (`src/services/Ranking.ts`)
- 제출 필드: `{ playerId, nickname, score, survivedSec, characterId, stageId, maxCombo, seed, clientVersion, outcome: 'victory' | 'complete' | 'over', continued? }` → 결과로 `{ rank }`.
- 조회: 기간별 Top 100 `[{ rank, nickname, score, survivedSec, characterId, outcome, continued, createdAt }]`, 내 순위.
- 규칙: 일간 / 주간(월요일 0시 기준) / 전체. 정렬은 점수 → 버틴 시간 → 먼저 등록한 순.
- 클라이언트: `Ranking` 인터페이스(`submit / top / me`)에 `LocalRanking`(localStorage, 최대 100행)과 나중의 `RemoteRanking`. 오프라인·서버 오류면 로컬로 폴백한다.
- 점수 검증(온라인 랭킹 때 정할 것): 한 판 100초 동안의 이론상 최대치를 넘는 점수는 거부하고, 제출 간격을 제한한다. 보안 규칙으로 할지(무료 요금제) Cloud Functions로 할지(종량제) 정한다.

## 수익 모델 (나중) — 밸런스에 영향 없음

출시 초기에는 **기부 + 가벼운 광고**만 운영하고, 상점은 리텐션이 확인된 뒤 연다. 상점 화면 자리는 이미 있고 지금은 '준비 중'이다.

| 모델 | 내용 | 금지 |
|---|---|---|
| 상점 | 등불지기 외형(색·모자·목도리), 빛 색(지금은 밤을 지나면 열림). 성능 영향 없음 | 능력치·아이템 판매 |
| 광고 | 오늘은 여기까지 뒤 선택형 보상 광고 1회 → 이어하기(제안: 하트 1개로). 랭킹에는 `continued` 표시 | 강제 전면 광고, 플레이 중 배너 |
| 기부 | 외부 후원 페이지. 감사 표시로 작은 배지 | — |

## 플레이 환경 점검표

- [ ] 시각 반응: 시간대 배경 보간, 콤보 단계마다 "콤보 ×N"과 마을 불빛, 피격 번쩍임·작은 흔들림, 맵 광도 어둠(`visual-audio.md`)
- [ ] 위 HUD: 달 / 밤 시간·진행 바 / 점수 / 콤보(safe area, 터치 요소 없음). 아래 HUD: 하트·HP·LP·광원 막대·켠 등불 수·아이템 칸·일시정지(엄지 영역, 44px 이상). 양쪽 두 스틱
- [ ] 진동: 맞음·등불·콤보·친구 구출, 설정에서 끄기, 미지원 기기는 조용히 건너뜀
- [ ] 조작법: 설정의 조작 설명 1장(두 스틱 그림), 튜토리얼 6단계
- [ ] 화면 4종(PC 풀 화면·PC 세로·모바일 세로·모바일 가로) + 태블릿·16:10·작은 폰에서 잘림 없음. 판 중에 돌리면 자동 일시정지(프로젝트 스킬 `ld-screen-check`)
- [ ] 성능: 모바일 60fps, 파티클 상한, 분류별 시트 + `manifest.json`
