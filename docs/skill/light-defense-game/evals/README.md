# 라이트 디펜스 스킬 평가 과제 (2026-11-18 개편본)

이 스킬을 읽은 모델이 **이 게임의 규칙을 실제로 아는지** 가려내는 과제 3개다. 2026-10-23 `.skill`의 옛 평가 3개는 옛 기획(120초·손 등불·콤보 절반 감소)이 기대값이라 쓰지 않는다.

- 작성만 해 두었다. 실행은 라이언이 따로 지시할 때 한다.
- 프롬프트에는 수치를 주지 않는다. 한 판 길이, 시간대 경계, 콤보 유지 시간, 등불 점화·감소, 데드존 같은 값은 스킬에서 찾아야 한다. 숨긴 테스트가 그 값을 확인한다.
- 늘 통과해서 가려내지 못하는 항목은 넣지 않는다. 예: "Phaser import 없음 + 테스트 파일 있음", "금지어 없음", "주인공에게 피해 없음".

## 구성

```
evals/
├─ _template/            빈 TypeScript + Vitest 프로젝트(각 과제의 시작 작업 폴더)
└─ NN-<이름>/
   ├─ prompt.md          모델에게 주는 요청(한국어, 라이언이 하는 말투)
   ├─ case.yaml          id·스킬·작업 폴더·기대 파일·채점 단계
   └─ graders/
      ├─ hidden.test.ts  숨긴 Vitest 테스트(채점 때만 tests/__hidden__/에 복사)
      └─ rubric.md       사람·모델 채점 기준(숨긴 테스트로 못 재는 것만)
```

| 과제 | 확인하는 규칙(스킬 출처) |
|---|---|
| `01-night-clock-combo` | 한 판 100초, 시간대 40%/70%(70%부터 클라이맥스), 콤보 3초 안에 다음 처리가 없으면 0으로, 배율 1 + ⌊콤보÷5⌋×0.5 최대 4 — `gameplay-systems.md` 스테이지·콤보 |
| `02-lamp-station` | 등불 점화 0.8초(토리 ×0.5), 켜지면 HP 가득 + 중앙 광원 +8, 저절로 초당 1.3 감소, 적 피해 ×0.6, 결계 반지름 = 200 × 광도/100, 켜진 동안 빛으로 회복 없음 — `gameplay-systems.md` 광도·결계 |
| `03-two-stick-input` | 빛 스틱 겨눔 문턱 35%, 짧게 탭 = 가장 가까운 적(몸 가장자리 기준, 없으면 안 쏨), 끌었다 가운데 = 취소, 누른 채 0.12초 뒤 반자동, 끌면 반자동 멈춤 — `gameplay-systems.md` 조작 |

## 돌리는 법 (실행 지시가 있을 때)

1. `_template/`을 새 빈 폴더로 복사하고 `npm i`를 한다.
2. 이 스킬을 켠 모델에게 `prompt.md`를 그대로 준다. 모델은 그 폴더 안에서 작업한다.
3. `case.yaml`의 `grade` 단계대로 채점한다.
   - `graders/hidden.test.ts`를 `tests/__hidden__/`에 복사하고 `npx vitest run tests/__hidden__`.
   - 그다음 `graders/rubric.md`로 채점한다.
4. 점수 = 숨긴 테스트 통과 비율 × 0.7 + 루브릭 × 0.3. 스킬을 끈 모델과 견주어 차이를 본다.

주의: 이 폴더는 스킬 zip에 함께 들어간다. 평가받는 모델이 `graders/`를 읽으면 답이 새므로, 실제로 돌릴 때는 `evals/`를 뺀 스킬로 돌린다.
