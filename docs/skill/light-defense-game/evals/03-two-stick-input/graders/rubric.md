# 루브릭 — 03 빛 스틱 입력

숨긴 테스트로 못 재는 것만 본다. 항목마다 0 / 0.5 / 1점, 합을 항목 수로 나눈다.

1. **입력과 게임을 이벤트로만 잇는가.** 어댑터는 `input:*` 이벤트만 내보내고, 게임 상태(적 목록·빛 대기)를 직접 만지지 않는다. 자동 조준 대상 고르기·발사는 게임 쪽(`autoAimAngle`을 부르는 곳)의 일로 나눴다.
2. **두 스틱의 문턱을 구별하는가.** 빛 스틱 겨눔 문턱(35%)과 이동 스틱 데드존(18%)이 다르다는 것과 그 이유(누르기만 한 엄지가 조금 밀려도 반자동이 유지되게)를 답이나 주석에 적었다.
3. **반자동과 짧게 탭이 한 번 누름에 두 발을 쏘지 않게 했는가.** `tapAllowed`를 어떻게 써서 막는지 어댑터와 게임 쪽 흐름이 맞게 설명·구현되어 있다.
4. **모델이 쓴 테스트가 규칙의 경계를 검사하는가.** 30%/40% 문턱, 취소, 대상 없음(null), 0.12초 앞뒤, 끌면 반자동 멈춤을 확인하는 테스트가 있고 통과한다.
