# 루브릭 — 01 밤 시계 + 콤보

숨긴 테스트로 못 재는 것만 본다. 항목마다 0 / 0.5 / 1점, 합을 항목 수로 나눈다.

1. **기본값의 출처가 게임 규칙인가.** 한 판 100초, 40%·70%, 콤보 3초, 배율 공식이 이 게임의 값으로 들어갔고, 근거(스킬의 어느 규칙인지)를 주석이나 답에 적었다. 옛 기획 값(120초, 40/90/120초 경계, 콤보 2초·절반 감소)이 한 군데라도 섞이면 0.
2. **시간대 경계가 진행률로 계산되는가.** 40초·70초 같은 초 단위 상수가 아니라 `durationSec × 0.4 / 0.7`(또는 진행률 비교)로 계산한다. 다른 길이의 판에도 맞는다.
3. **모델이 쓴 테스트가 경계를 실제로 검사하는가.** 39.9/40·69.9/70초, 2.9/3.1초, 콤보 4/5·29/30/31 같은 바로 앞뒤 값을 확인하는 테스트가 있고 통과한다. 테스트가 있기만 하고 경계를 안 보면 0.5.
4. **시간을 dt로만 다루는가.** `Date.now`·`setTimeout`·`performance.now` 없이 `update(dt)` 누적으로만 진행한다.
