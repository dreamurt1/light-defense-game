# 루브릭 — 02 등불 스테이션

숨긴 테스트로 못 재는 것만 본다. 항목마다 0 / 0.5 / 1점, 합을 항목 수로 나눈다.

1. **이 게임의 등불 모델인가.** 등불은 '등불지기가 손에 든 등불(HP·불꽃 5개)'이 아니라 맵 외곽에 놓인 스테이션이다. 켜면 중앙 광원이 오르고, 켜진 동안 저절로 흐려지며, 다시 켜려면 꺼질 때까지 기다린다. 옛 기획의 손 등불·대광원·시너지 개념이 섞이면 0.
2. **수치를 한곳에 모았는가.** 0.8·1.3·0.6·200·8을 코드 곳곳에 흩지 않고 설정 객체(기본값)로 모았고, 근거(스킬 규칙)를 적었다.
3. **결계의 의미를 이해했는가.** 답이나 주석에서 결계를 '대부분의 적이 피해 돌아가는 둘레, 어두워질수록 줄고 등불 몸까지 줄면 적이 등불을 공격'으로 설명한다(구현 범위 밖이어도 설명은 맞아야 함).
4. **모델이 쓴 테스트가 경계를 실제로 검사하는가.** 0.79/0.81초 점화, 감소율, ×0.6, 꺼짐 알림 한 번을 확인하는 테스트가 있고 통과한다.
