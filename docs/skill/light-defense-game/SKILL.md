# 라이트 디펜스 (Light Defense) 개발 스킬

> 2026-11-06 개정: 이 스킬은 프로젝트 CLAUDE.md의 결정과 맞춰져 있다.

이 스킬은 라이언이 마인드맵으로 잡고 기획서(통합본, 2026-10-23)로 확정한 "라이트 디펜스"를 **클로드 코드가 일관되게 구현**할 수 있도록 기획을 고정한 게임 바이블이다. 세계관·이름·수치·화면 흐름이 전부 여기 정해져 있으므로, 코드를 쓸 때 새로 지어내지 말고 이 문서와 `references/`를 기준으로 삼는다. 우선순위는 **라이언의 지시 > 가장 최근 수정 > 더 구체적인 쪽**이고, 라이언이 바꾸면 이 스킬을 고치는 것이 우선이다(코드보다 문서가 원본). 프로젝트 안에서는 CLAUDE.md의 "라이언 지시 기록"이 이 스킬보다 앞선다.

## 한 줄 정의

> **"탭 한 번, 빛 한 줄기. 오늘 밤도 끝까지."** — 작은 동물 "등불지기"가 태양이 잠든 반딜마을에서 **등불을 손에 들고** 마을을 걸으며, 빛 스틱으로 겨눈 방향에 **부채꼴 빛**을 보내 어둠에 변형된 이웃(악당)을 되돌리고 **새벽(120초)까지 등불을 지키는** 모바일 세로 화면 아케이드 디펜스. 콤보와 장착물로 점수를 불려 랭킹에 도전한다. (2026-11-04 개정: 기획서의 '탭 하나·이동 없음'을 브롤스타즈식 두 스틱으로 대체. 슬로건은 그대로 쓴다.)

핵심 축 네 가지를 항상 지킨다.

1. **조작은 두 스틱(브롤스타즈식, 2026-11-04 개정).** 등불지기는 등불을 손에 들고 넓은 마을을 걷고, 카메라가 따라간다. 왼쪽 아래 **이동 스틱** = 끄는 방향으로 걷기. 오른쪽 아래 **빛 스틱** = 끌면 **루미의 중심**에서 60° 원뿔 범위가 보이고(반지름은 끈 거리에 비례, 끝까지 끌면 캐릭터 최대 사거리 — 2026-11-06 개정), 놓으면 발사한다. 짧게 탭하면 가장 가까운 이웃에게 자동 조준(사거리 끝까지), 끌었다가 가운데로 되돌려 놓으면 취소. 다음 발사까지 0.4초(캐릭터 배율 적용) 대기. PC는 WASD·방향키로 걷고, 마우스 왼쪽 버튼을 누른 채 끄는 동안 원뿔이 보이며(반지름 = 루미 중심에서 커서까지 거리, 최대 사거리까지) 놓으면 발사한다(2026-11-06 개정). 판단이 안 서는 조작 세부는 브롤스타즈의 공격 방식을 따른다.
2. **빛은 공격이 아니라 되돌림이다.** 악당은 죽지 않고 "제 모습을 되찾고 물러난다". 피·폭발·비명 금지. 결과 화면의 처치 수는 "되찾은 이웃"으로 표기.
3. **한 판 = 하룻밤 120초.** 난이도 곡선은 시간대(초저녁 0~40 → 한밤 40~90 → 새벽 전 90~120초)이고, 게임 오버는 패배가 아니라 "오늘 밤은 여기까지".
4. **톤은 차분하고 은은하되, 플레이는 캐주얼하고 박진감 있게.** 세계관은 배경에만 두고 플레이어에게 설명하지 않는다(컷신·대사·튜토리얼 텍스트 없음). 콤보가 터질 때 화면·소리·진동이 같이 반응한다.

## 기술 스택 (고정)

- **Phaser 3 (3.80+) + TypeScript + Vite**, 브라우저 전용. **모바일 세로 화면이 기준**이고 PC에서는 9:16 박스를 가운데 두고 양옆 배경만 넓힌다. PC 조작은 WASD·방향키 + 마우스 끌었다 놓기(2026-11-06 개정).
- 화면(뷰포트)은 세로 540×960 / 가로 높이 540·폭은 화면 비율 720~1280(짧은 변 540 고정 = 물체 크기는 그대로, 보는 프레임만 바뀜, 2026-11-06), `Scale.FIT` + `CENTER_BOTH`. 휴대폰은 기기 방향, PC는 창을 꽉 채우는 가로(설정에서 세로). 마을(월드)은 **16:9 3200×1800**(2026-11-06, 처음 정사각 2400×2400과 면적 같음 — 풀숲·장애물은 크기 그대로 위치만 옮김), 시작 위치 가운데(1600, 900) (2026-11-06 개정).
- 밸런스 수치는 코드에 하드코딩하지 않고 `src/data/*.json`에서 읽는다(이 스킬의 `assets/data/`를 그대로 복사, 풀숲·장애물 배치는 `map.json`). 수치 조정 요청이 오면 JSON만 바꾼다.
- 메뉴 화면과 HUD는 캔버스 위 **HTML/CSS 오버레이**(프레임워크 없이 TS, 2026-10-28 개정)이고, Phaser는 Boot → Preload → Play 씬만 돈다. 씬 ↔ DOM UI는 `src/core/events.ts` 이벤트로만 주고받는다.
- 그림: 아트 디렉션은 `reference/ChatGPT-Images/`(1순위 「달빛 숲의 등불지기 고양이.png」, 2026-10-30 개정). **실제 그림은 라이언이 ChatGPT로 생성**해 `art-src/<분류>/`에 넣고 `npm run art:import`로 `public/assets/` 시트와 `manifest.json`에 내보낸다(2026-11-04 개정). 그림이 아직 없는 키는 `src/art/*`(Canvas 2D 코드 그림)가 대신한다. 키는 `TextureKeys`·`AnimKeys` 한 곳에서 관리한다. 이전의 'Phaser Graphics 단순 도형 플레이스홀더' 계획은 쓰지 않는다.
- 서버는 직접 운영하지 않고 **Firebase로 대체**한다(2026-10-28 개정): Hosting(M1부터 휴대폰 확인용 배포) + Authentication(Google) + Firestore(`asia-northeast3` 서울). M4까지 랭킹은 `localStorage`(`LocalRanking`)에 저장하고, M5에서 `RemoteRanking`이 Firestore SDK로 직접 읽고 쓴다.
- 목표 성능: 모바일 브라우저 60fps, 한 사람이 유지보수 가능한 규모.

## 구현 순서 (마일스톤)

요청이 "게임 만들어줘"처럼 넓으면 **M1 코어 루프부터** 만들고 멈춰서 보여준다. 전부 한 번에 만들지 않는다 — "빛을 만드는 손맛"이 재미있지 않으면 나머지는 의미가 없다.

| 단계 | 목표 | 포함 | 완료 기준 |
|---|---|---|---|
| M0 | 뼈대 | Vite + Phaser + TS, 씬 라우팅, 데이터 로더, `rng.ts`, `events.ts` | `npm run dev`로 남색 세로 화면 + 등불 원이 뜬다 |
| M1 | **코어 루프, 손맛 검증** | 순수 TS `ComboSystem`·`NightClock`·`ScoreCalculator` + Vitest, PlayScene에 루미·파닥·부채꼴 빛(2026-11-04부터 두 스틱 조작·넓은 마을·카메라)·등불 HP·게임 오버, `LocalRanking` | 본인이 10판 연속으로 하고 싶은가 |
| M2 | 악당과 웨이브 | 악당 6종(킥킥 무리, 말랑 분열, 호오 은신, 노월 방해), `Spawner` + `waves.json`, 방해 요소, 아이템 2종, 클리어(새벽) | 120초 난이도 곡선이 성립한다 |
| M3 | 캐릭터와 장착물 | 주인공 5종 특성, 장착물 4종, 선택 화면(주인공+장착물 한 화면), 해금 조건 | 캐릭터마다 플레이 느낌이 다른가 |
| M4 | 연출과 오디오 | 팔레트, Entry·Result 연출, `AudioBus`(BGM·효과음·목소리), 진동, 설정 | 지인 테스트에서 세계관을 설명 없이 이해하는가 |
| M5 | Firebase와 랭킹 (2026-10-28 개정) | Firebase Auth(Google) + Firestore 랭킹, `RemoteRanking`, 점수 검증 | 점수 제출 → 조회 왕복이 된다 |
| M6 | 수익과 출시 | 기부 버튼, 보상형 광고 이어하기(`continued` 표시), 템 샵 기본 스킨 3종 | 공개 링크 배포 |

각 단계의 상세 작업과 파일 목록은 `references/tech-and-roadmap.md`에 있다.

## 코드를 쓸 때 지킬 규칙

- **이름을 바꾸지 않는다.** 캐릭터·악당·아이템·장착물의 한국어 이름, 영문 이름, 코드 `id`는 `characters.md`, `assets/data/`에 있는 것을 그대로 쓴다. UI 텍스트는 한국어, 코드 식별자는 영어 id.
- **수치는 JSON, 로직은 TS.** 새 수치가 필요하면 먼저 JSON 스키마에 필드를 추가하고 문서에 적는다.
- **기획서에 없는 수치를 만나면** 지어내서 조용히 넣지 않는다. 합리적인 기본값을 고르되 코드 주석과 완료 보고에 "제안: 기획서에 없음"으로 표시하고, 해당 `references/` 표에도 같은 표시로 추가한다. 라이언이 확인하면 표시를 지운다.
- **요청한 범위만 만든다.** 화면이나 씬 하나를 부탁받았으면 그것과 꼭 필요한 타입만 만들고, 아직 없는 공통 모듈(`RunState`, `AudioBus` 등)은 최소 인터페이스만 가정한 채 "다음에 필요한 것"으로 보고한다. 로드맵의 다른 마일스톤을 앞당겨 만들지 않는다 — 코드가 늘수록 라이언이 확인할 양도 는다.
- **시스템은 독립 클래스**로 나눈다(`ComboSystem`, `Spawner`, `NightClock`, `LightSystem`, `HazardSystem`, `AudioBus`, `Haptics`). PlayScene은 이들을 조립만 한다 — 씬 파일 하나가 600줄을 넘기면 분리한다.
- **이벤트로 연결한다.** 콤보 변화, 악당 되돌림, 등불 피격, 시간대 전환은 `gameplay-systems.md`의 이벤트 표대로 발행하고 HUD·사운드·진동은 그 이벤트를 구독한다. 게임 로직은 연출을 모른다. 두 스틱(DOM)은 `input:move / input:aim / input:fire` 이벤트로만 게임에 입력을 보낸다(2026-11-04 개정).
- **결정적 테스트 가능성.** 스폰·아이템 드롭의 난수는 `seed`를 받는 RNG 한 곳(`src/core/rng.ts`)에서 뽑는다. `ComboSystem`, `NightClock`, `ScoreCalculator`, `Spawner`의 선택 로직, 부채꼴 판정 `inFan()`, 스틱 판정(`movement.ts`·`aimStick.ts`)은 Phaser 의존 없이 쓰고 Vitest 단위 테스트를 붙인다.
- **접근성·안전.** 깜빡임은 초당 3회 이하, 진동은 설정에서 끌 수 있게(iOS Safari처럼 미지원이면 조용히 건너뜀), 소리는 첫 사용자 입력 이후에만 재생(브라우저 자동재생 정책). 상단 safe area(노치) 아래에 UI를 두고 터치 표적은 최소 44px. 두 스틱은 화면 구석에 너무 붙이지 않는다.
- **톤.** 텍스트·연출은 `world-and-story.md`의 문장 목록에서 가져온다. 새 문장이 필요하면 같은 결(짧고, 따뜻하고, 패배감 없음)로 쓰고 그 문서의 표에 추가한다. 금지어: 패배, 죽, 처치, 킬, 실패.

## 요청 유형별 대응

- **"처음부터 만들어줘 / 프로젝트 세팅"** → M0~M1까지 만들고 실행 방법과 조작법(왼쪽 스틱 걷기 · 오른쪽 스틱 끌었다 놓아 빛, PC는 WASD + 마우스 끌었다 놓기)을 알려준 뒤 멈춘다.
- **"X 캐릭터/악당 추가·수정"** → `characters.md`의 표와 `assets/data/characters.json` 또는 `enemies.json`을 수정하고, 행동 패턴은 `src/entities/enemies/<Id>.ts`에 구현한다.
- **"밸런스가 이상하다"** → 수치 조정은 JSON에서. 바꾼 값과 이유를 `references/`의 해당 표에도 반영한다. 120초 밤에서 마리 수가 부족하게 느껴지면 생성 간격을 먼저 줄인다.
- **"기획 보강해줘 / 시나리오 더 써줘"** → 코드가 아니라 `references/` 문서를 확장한다. 남은 결정 사항(`tech-and-roadmap.md` 마지막 절)은 라이언에게 묻는다.
- **"사운드/연출 붙여줘"** → `visual-audio.md`의 트리거 표를 따라 이벤트 구독 방식으로 붙인다. 오디오 파일이 없으면 Web Audio로 합성한 임시음을 쓰고 키 이름만 맞춘다.
- **"그림 바꿔줘 / 에셋 넣어줘"** → 그림은 라이언이 ChatGPT로 만든다. 주문서 `docs/art-order.md`(프롬프트·크기·포즈)를 고치고, 받은 PNG를 `art-src/<분류>/`에 넣어 `npm run art:import`로 내보낸다.

## 이 스킬이 다루지 않는 것

- 실제 그림 생성(일러스트, 스프라이트 시트) — 그림은 라이언이 ChatGPT로 만든다. 이 스킬은 규격과 가져오기 경로(`art-src/` → `npm run art:import` → `public/assets/`)만 정한다.
- 멀티플레이 — 싱글 플레이 + 비동기 랭킹만 다룬다.
- 결제 연동의 법적·세무 사항 — M6에서 라이언이 별도로 결정한다.
