# 그림 주문서 — ChatGPT로 게임 그림 만들기

라이트 디펜스의 캐릭터·적·소품·배경을 ChatGPT로 생성해 게임에 넣는 방법이다. 지금 게임 속 그림은 코드로 그린 임시 그림이고, 아래 파일을 `art-src/` 폴더에 넣으면 그 그림으로 바뀐다.
2026-11-04 기준. 등불지기가 등불을 들고 넓은 정사각 마을(2400×2400)을 걷는 두 스틱 조작에 맞췄다. 마을 안에는 숨을 수 있는 풀숲과 지나갈 수 없는 바위·술통·등불 기둥이 있다(전체 지도 `sketches/map-overview.png`).

## 쓰는 법

1. ChatGPT에서 **새 대화**를 열고 레퍼런스 두 장을 먼저 올린다.
   - `reference/ChatGPT-Images/light_defense_sprite_asset_reference_sheet.png`
   - `reference/ChatGPT-Images/달빛 숲의 등불지기 고양이.png`
2. 아래 **공통 스타일**을 첫 메시지로 붙여 넣는다.
3. 표의 프롬프트를 **위에서부터 한 장씩** 요청한다. 같은 대화 안에서 이어 가야 그림체가 맞는다.
4. 받은 그림을 표의 **파일 이름 그대로** `art-src/<분류>/` 폴더에 저장한다.
   - 예: `art-src/characters/keeper-lumi.png`
5. Claude에게 "그림 넣었어"라고 하거나 `npm run art:import`를 실행한다.
   - 가져오기 도구가 배경 지우기, 포즈 나누기, 크기·위치 맞추기, 고해상도 시트 만들기를 자동으로 한다.
   - 잘못된 그림이 있으면 무엇이 문제인지(예: "포즈 2개를 기대했는데 1개") 알려 주고, 그 그림만 코드 그림으로 남긴다.

## 공통 규칙 (모든 그림)

- **배경은 투명**하게 요청한다("배경은 투명한 PNG로").
  - 투명이 안 되면 **단색 마젠타(#FF00FF) 배경**으로 받는다. 도구가 지운다.
  - 흰색·검은색 배경은 안 된다. 루미가 검은 고양이라 몸까지 지워진다.
- **포즈가 여러 개**면 한 장에 **왼쪽부터 나란히, 사이를 넉넉히 띄워서** 그린다. 겹치면 나눌 수 없다.
  - 또는 포즈마다 따로 받아 `keeper-lumi.idle.png`처럼 `이름.포즈.png`로 저장해도 된다.
- 글자, 카드 테두리, 바닥 그림자, 배경 소품은 넣지 않는다. 그림자와 빛은 게임이 그린다.
- 시점은 **살짝 내려다보는 3/4**(2.5D 톱다운). 캐릭터는 **오른쪽을 보게** 그린다. 왼쪽은 게임이 뒤집어 쓴다.
- 크기는 1024px 이상.
- **캐릭터는 기획서가 우선**이다. 레퍼런스 시트와 동물이 다르면 기획서를 따른다(`docs/reference-crosscheck.md`).
  - 등불지기: 토리=토끼, 도토=햄스터, 바루=카피바라, 몽이=강아지.
  - 이웃: 파닥=박쥐, 그르르=악어, 말랑=슬라임, 호오=유령, 킥킥=하이에나.

### 프롬프트

**루미 고해상도 시트 (선택, 2026-11-04)** → `reference/LUMI-sprites/`의 시트를 바꿔 넣고 `src/art/lumiSheet.ts`의 `LUMI_SHEET.url`·`scale`을 고친 뒤 `npm run art:lumi` → `npm run art:import`
> 첨부한 루미 캐릭터 에셋 시트와 **배치·순서는 똑같이**, 해상도만 2배(3072×2048)로 다시 그려 줘. 특히 '애니메이션 스프라이트 시트'는 8줄이 실제로 8방향(↑ 뒷모습, ↗ 오른쪽 뒤, → 오른쪽, ↘ 오른쪽 앞, ↓ 정면, ↙ 왼쪽 앞, ← 왼쪽, ↖ 왼쪽 뒤)이 되게, 각 상태(대기·걷기·공격·피격)는 같은 크기·같은 발 위치로.
> (지금 시트는 표의 8줄 중 여러 줄이 같은 방향이라, 없는 방향은 턴어라운드 모습을 흔들어 대신 쓰고 있다)

**루미 8방향 동작 팩 (선택, 제안, 2026-11-06)** → 걷기는 받아서 적용함(`Lumi_Walk_8D_4Frames_Pack`, 8방향 × 4프레임). 공격·피격도 같은 형식(256×256, 방향별 폴더, manifest)으로 받으면 시트 대신 팩으로 바꿀 수 있다 (가져오기 코드는 받은 뒤에 붙인다). 아래 요청문의 걷기 부분은 이미 받았으니 공격·피격만 요청. 그 전까지 게임은 팩 그림 + 동작 효과로 공격·피격을 보인다(2026-11-06)
> 첨부한 'Lumi Idle 8-Direction Sprite Pack'과 같은 루미·같은 그림체·같은 크기(256×256 투명 PNG, 발끝 위치 동일)로 **걷기** 8방향 팩을 만들어 줘. 방향은 같은 manifest 규칙(0° 정면, 45° 오른쪽 앞, 90° 오른쪽, 135° 오른쪽 뒤, 180° 뒷모습, 225°·270°·315°는 135°·90°·45°를 좌우로 뒤집기)으로, 방향마다 한 걸음 한 바퀴를 6프레임으로 나눠 `lumi_walk_<각도>_<이름>_<0~5>.png`. 네 발로 걷는 고양이 걸음, 앉은 자세가 아닌 선 자세. 같은 형식의 manifest.json도 함께.
> (공격: 앞발을 내밀어 빛을 보내는 3프레임 `lumi_attack_…`, 피격: 움찔 2프레임 `lumi_hit_…`도 같은 방식으로 따로 요청)
