# 홈 화면 기획 (2026-11-18, Claude Code 정본)

> 라이언 요청(2026-11-18):
> - 홈 그림의 캐릭터·등불 위치와 게임 버튼 위치가 엇갈린다.
> - 리본이 뒤쪽 귀에 있는 오류가 남아 있다.
> - 그래서 홈 화면을 여기서 처음부터 기획하고, 그에 맞춰 ChatGPT 지시서를 다시 만든다.

## 4. 요소와 상태

- **제목 PNG**: 받은 투명 제목.
  - 오기 전이나 원본과 다르게 오면: 지금 그림(Moonlit Forest)에서 제목을 잘라, 밝기를 투명도로 바꾼 판을 쓴다(와이어프레임과 같은 방법).
  - 영문 글자 로고(`.logo__en`)는 화면 읽기용으로만 남긴다.
- **한글 이름·슬로건**: '라이트 디펜스'(자간 넓게) + "작은 빛으로, 마을을 되찾아요."
- ~~무대 등불지기~~: 뺐다(라이언, 캐릭터 없이). 프로필 사진만 고른 등불지기로 바뀐다.
- **보조 버튼 넷**: 지난 밤들 · 상점 · 튜토리얼 · 테스트. 둥근 배지 규칙(5절)을 따른다.
  - 남색 유리 원, 굵은 둥근 선 아이콘(`ui/icons.ts`), 아래 글자.
  - 세로 = 한 줄 넷, 가로 = 2×2.
- **게임하기**: `pill--primary`. 세로 = 맨 아래 가운데(엄지 자리), 가로 = 메뉴 열 맨 아래.
- **프로필·설정**: 지금 것. 세로는 프로필 왼쪽 위, 가로는 왼쪽 아래.

## 5. 구현 (그림이 온 뒤)

1. `art-src/backgrounds/home.png`(세로), `home-wide.png`(가로)를 둔다. registry에 `home-wide`를 더한다(webp). 제목은 `art-src/ui/home-title.png` → `public/assets/ui/`.
2. **장면 상자** `.home__scene`: 그림 비율 그대로 화면을 덮고 가운데에 둔다. `.stage`가 size 컨테이너다.
   - 세로: `width: max(100cqw, 100cqh * 1080 / 2340)`
   - 가로: `width: max(100cqw, 100cqh * 2340 / 1080)`
   - 배경과 무대 등불지기는 이 상자 안에서 그림 %로 놓는다(그림 속 빈터에 정확히 선다).
   - 제목·버튼·프로필은 화면 기준(UI 층)으로 놓는다.
3. `HomeScreen.ts`: 무대 `<img>`(누르면 `ui:navigate select`), 제목 `<img>`, 보조 버튼을 둥근 배지로, 세로·가로 배치 CSS(`screens.css` 홈 절을 새로).
4. PC 세로: `:root[data-screen='home']`일 때 body 뒤에 흐린 세로 그림.
5. 받은 그림의 실제 등불 위치를 재서 등불지기 좌표(CSS 변수)를 맞춘다.
6. 확인: 화면 4종 + 태블릿·16:10을 헤드리스로 찍는다. 무대에 루미·토리·도토를 바꿔 본다. 콘솔 오류 0, 테스트·빌드, 배포.

## 6. 적용 결과 (2026-11-18, 받은 그림에 맞춘 최종 배치)

- 점검·다듬기: `reference/Home_Art_Pack/README_claude.md`. 세로 등불은 x 77%·받침 아래 70.5%, 가로 등불은 x 51.7%·98.5%였다. 가로의 마을·달은 오른쪽 65~88%에 있었다.
- **세로**: 제목·한글 이름·슬로건은 위 가운데. 메뉴는 아래 가운데(둥근 버튼 넷 한 줄 + 게임하기). 프로필은 왼쪽 위.
- **가로**: 제목은 **위 가운데**(맑은 하늘). 메뉴는 **오른쪽 아래, 마을 밑**(둥근 버튼 넷 한 줄 + 게임하기, 폭 360u). 프로필은 왼쪽 아래.
- **좁은 가로**: 16:10보다 좁으면 메뉴 폭 290u. 3:2보다 좁으면(4:3) 장면을 왼쪽으로 50u 옮겨 그림 속 등불이 메뉴에서 떨어지게.
- **메뉴 높이 (2026-11-18 라이언: 버튼이 너무 하단에 있지 않게)**: 아래 여백 세로 = 화면 높이의 7%, 가로 = 10%(그 전 26~30u). 더 올리면 그림 속 등불 받침(세로 9:16)·언덕 위 마을(가로)에 닿는다. 키가 낮은 화면은 손가락용 최소 크기 때문에 메뉴가 높아져, 폰 가로(높이 430px 이하) 7%·16:9 작은 폰 세로(700px 이하) 4.5%. 가로 메뉴 폭 340u(PC 16:9에서 게임하기가 등불에 걸리지 않게). 화면 7종에서 단추가 등불·마을과 겹치지 않음을 수치로 확인.
- **PC 세로 화면**: 양옆 띠에 흐린 세로 그림.
- **확인한 화면**: PC 풀 1920×1080, PC 세로(설정), 모바일 세로 390×844, 모바일 가로 844×390, 태블릿 세로 820×1180, 4:3 1180×820, 16:10 1440×900, 3:2 1500×1000. 버튼·제목·프로필이 겹치지 않고, 그림 속 등불이 메뉴에 가리지 않는다.
- **캐릭터 없이 (2026-11-18 라이언)**: 무대 등불지기를 빼고 같은 화면 6종으로 다시 확인했다.
