## 5. 구현 (그림이 온 뒤)

1. `art-src/backgrounds/home.png`(세로), `home-wide.png`(가로)를 둔다. registry에 `home-wide`를 더한다(webp). 제목은 `art-src/ui/home-title.png` → `public/assets/ui/`.
2. **장면 상자** `.home__scene`: 그림 비율 그대로 화면을 덮고 가운데에 둔다. `.stage`가 size 컨테이너다.
   - 세로: `width: max(100cqw, 100cqh * 1080 / 2340)`
   - 가로: `width: max(100cqw, 100cqh * 2340 / 1080)`
   - 배경과 무대 등불지기는 이 상자 안에서 그림 %로 놓는다(그림 속 빈터에 정확히 선다).
   - 제목·버튼·프로필은 화면 기준(UI 층)으로 놓는다.
3. `HomeScreen.ts`: 무대 `<img>`(누르면 `ui:navigate select`), 제목 `<img>`, 보조 버튼을 둥근 배지로, 세로·가로 배치 CSS(`screens.css` 홈 절을 새로).
4. PC 세로: `:root[data-screen='home']`일 때 body 뒤에 흐린 세로 그림.
5. 받은 그림의 실제 등불 위치를 재서 등불지기 좌표(CSS 변수)를 맞춘다.
6. 확인: 화면 4종 + 태블릿·16:10을 헤드리스로 찍는다. 무대에 루미·토리·도토를 바꿔 본다. 콘솔 오류 0, 테스트·빌드, 배포.
