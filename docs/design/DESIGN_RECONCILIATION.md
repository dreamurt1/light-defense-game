## 2. 확정된 일치 사항

- **세계관**: 빛의 마을과 어둠의 마을. 중앙 광원의 파편으로 얻은 힘, 노월의 동기, 공존 메시지. 옛 '태양이 잠든 마을' 설정은 쓰지 않는다.
- **세 주인공**: 루미(검은 고양이·주황 스카프·초록 눈, 등불을 들지 않음), 토리(흰 아기 토끼·민트 리본·한쪽 귀 접힘), 도토(붉은 갈색 아기 다람쥐·황금 도토리). 친구 둘은 구출하면 해금된다.
- **조작과 시점**: 두 스틱으로 이동하며 쏘고, 2.5D로 살짝 내려다보는 시점이다.
- **빛**: 공격이 아니라 되찾아 주는 힘이다. 피·무기·폭발은 쓰지 않는다.
- **수치 체계**: 광도 4단계, LP는 들판 < 등불 < 광원 순으로 회복, 하트 3개.
- **판**: 아이템 5종, 점수 순서(등불 < 호스틸 < 구출 < 보스, 자비 있음), 100초에 70%부터 클라이맥스, 기본 승리와 완전 승리.
- **그림 기준**: 팔레트 주요 색, 스프라이트 규격(8방향 256, 걷기 8×4, 마젠타 배경).
- **서비스**: Firebase Hosting으로 웹 배포, 인증·랭킹·상점은 나중.

## 4. 코드에만 있거나 문서에만 있는 사항

**코드(와 Claude 문서)에만 있음** — 라이언 지시나 Claude 제안으로 들어간 것이다. 인계 문서는 모른다.
- **트라이얼**: 시작 자리 둘레에 고정된 적을 둔 연습장(11-14 라이언). 테스트 판은 기록에 남지 않는다.
- **필수 튜토리얼**: 이야기 카드 4장 뒤 6단계를 거친다(11-13 라이언).
- **등불 관련**: 결계, 자연 감소, 켜면 광원 +8, 어두워질수록 그쪽에서 적이 더 나옴(11-14 라이언).
- **적 움직임**: 몸박치기, 적 역할별 목표 고르기.
- **맵**: 풀숲에 4초 넘게 있으면 들킴, 돌담·울타리, 오두막 7채, 강과 다리 3개(11-13 라이언).
- **아이템**: 칸 2개, 누르는 순간 사용. 패배 위험이면 루미 곁에 생김(11-14 라이언).
- **스테이지 이름**: 처음 밤·첫 번째 밤·경계의 밤·어둠의 마을·노월의 밤.
- **화면과 조작 마무리**: 합성 사운드·D장조 배경음, 뒤로가기·앞으로가기, 당겨서 새로고침, 둥근 배지 디자인 규칙.

**문서에만 있음(아직 구현 안 함)**
- 일반 적 필살기 4유형(속도·체력·광도·방어). 노월만 구슬·소환이 있다.
- 완전 승리 추가 아이템 보상.
- 스테이지 시작 전 아이템 장착(상점과 함께).
- 노월 진정 뒤의 화해 장면. 지금은 대사와 결과 문구뿐이다.
- 계정·랭킹 서버, 상점, 광고, 기부.

## 6. 사용자 결정이 필요한 것 (남은 것)

괄호는 지금 기본값이다. 급하지 않아서, 그 기능을 만들 때 다시 묻는다.

1. 패시브를 여러 번 때리면 호스틸이 늘어나는 XMind식 분노를 더할지 (지금 방식만 유지)
2. 시작 전 아이템 고르기와 상점 (상점과 함께 나중에)
3. 완전 승리 추가 아이템 보상 (점수 ×2.5만)
4. 일반 적 필살기 4유형 (노월만)
5. 노월 진정 뒤 화해 장면의 범위 (대사·결과 문구만)
6. 계정·랭킹 서버·광고·기부 시점 (핵심 플레이 검증 뒤)
