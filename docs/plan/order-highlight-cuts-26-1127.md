> 밤이 100초로 반복되는데 사건(친구 구출·노월·첫 행렬·첫 완전 승리)이 일어나도 효과 하나·토스트 하나뿐이라 밋밋하다. **새 시스템 대신 "컷" 하나를 만들어 여러 사건에 꽂는다.** 두 가지 꼴: ① **그림 컷**(아침·결과처럼 시간이 멈춘 화면 위, 그림 + 제목 + 대사 1~2줄 + '계속') ② **초상 배너**(밤 중, 초상 + 한 줄, 2~3초, **판을 멈추지 않음**). 모두 처음 한 번만(`Progress.seenCuts`), 탭으로 넘김. 그림 3장은 ChatGPT가 만드는 중(`reference/Highlight_Cuts_v1/`, 이야기 카드 4장 뒤) — **오기 전에는 그림 없이 글만으로 먼저 라이브**(아침 배경 위 제목·대사).

## ① 그림 컷 `ui/HighlightCut.ts` (DOM 오버레이)

- 자리: 아침 화면(`MorningSheet`) 또는 결과 화면이 뜨기 **직전**에 전체 화면 컷 → '계속'(탭·버튼) → 원래 화면. 그림 1280×720 cover(`public/cuts/<id>.png`, 없으면 `morning` 배경), 아래 띠에 제목(종이색) + 대사 1~2줄(길 색이 아니라 호박빛 강조 한 단어까지). 2초 뒤부터 탭 가능(실수로 넘기지 않게), 시스템 뒤로가기 = 계속.
- 처음 한 번만: `Progress.seenCuts: string[]`(런이 끝나도 남음). 테스트 판·튜토리얼에서는 띄우지 않음(진행에 남지 않으므로).
- 문장표(`world-and-story.md` "하이라이트 컷" 절 신설):

| id | 때 | 제목 | 대사 |
|---|---|---|---|
| `cut-tori` | 토리를 되찾은 밤의 아침 | 토리와 다시 | 토리 "루미..! 빛이 따뜻해" / "이제 같이 갈게" |
| `cut-three` | 도토를 되찾은 밤의 아침 | 셋이 다시 모였어요 | 도토 "…도토리는 안 놓쳤어" / 토리 "이제 셋이야" |
| `cut-nowol` | 노월 진정 → 아침 | 노월이 마음을 열었어요 | 찾아온 노월 "…조금은 믿어 볼게" / 분노한 노월 "…이 빛, 생각보다 따뜻하네"(지금 `boss.calm/angry.calmLine` 그대로) |
| `cut-bright` | 첫 완전 승리의 아침 | 마을이 환해졌어요 | "등불이 모두 켜졌어요" / "마을이 숨을 쉬어요" — **그림 없음**(아침 배경 그대로) |

- 집으로 결과: 토리·도토를 둘 다 되찾은 런이면 결과 화면 위쪽 띠에 `cut-three` 그림(있을 때만)을 얇게 깔고 "무사히 돌아왔어요" 그대로. 컷으로 띄우지는 않음(결과 화면이 이미 매듭).
