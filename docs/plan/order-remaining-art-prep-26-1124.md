## 2. 받으면 (공통)

올빼미 절차: art-check(캔버스·앵커·투명·같은 축척) → 자리 → `npm run assets` → 헤드리스 캡처 → 그 폴더 `README_claude.md` → 스킬 `visual-audio.md` 임시 그림 목록 갱신 → zip → 보고 맨 위 "zip 다시 올리기 필요". **임시 코드 그림은 지우지 않는다**(폴백).

- **광원**: 세 장을 겹쳐 제단 위치가 같은지(±4px). 광도 4단계는 지금처럼 둘레 빛 크기로 — 밝음·중간·크게 밝음은 `source_bright`, 낮음은 `source_dim`, 꺼짐은 `source_off`.
- **등불**: 켜짐·약함·꺼짐 ↔ `lantern_on`·`lantern_dim`·`lantern_off`. 결계 원은 지금처럼 게임이.
- **아이템**: 바닥에 놓일 때 게임이 빛 원을 그리고 HUD 칸에도 같은 그림. id 대응은 `README_claude.md`에 표로.
- **소품**(들어갈 때만): 캔버스 = 칸×96 + 48 여백, 발자리 가운데(집은 지붕만 위로 96 더). 테마가 없는 소품은 `light`를 색조만 바꿔 쓴다. 울타리·강·다리는 한 칸 조각을 이어 붙임. 풀숲은 들어가면 반투명(지금 규칙). `check:maps` 6장 다시.
- **바닥**(들어갈 때만): 384×384 이음새 타일, 테마별. 격자선은 그리지 않는다.
