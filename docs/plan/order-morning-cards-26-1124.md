## 2. 배치 (기획)

- **아침 배경**: 아침 화면 뒤. 세로는 `morning.png`, 가로는 `morning-wide.png`(기존 홈 배경과 같은 방향 판정 규칙). 판이 덮지 않는 위·아래 띠에 나무·앞뜰이 보이도록 **cover 맞춤(잘라내기), 늘리지 않음**. "집으로" 결과 화면이 같은 하늘을 쓰게 되어 있으면(NIGHT_RUN 아침 절) 같은 그림을 쓴다 — 새 자리는 만들지 않는다.
- **새 지역 카드**: "새 지역을 발견했어요" 카드 상단 띠. B 구간 첫 아침 = `region-border`, C 구간 첫 아침 = `region-dark`. 지도 축소판은 왼쪽 1/3 위, 제목·설명은 오른쪽 — 지금 배치 그대로. 글 색은 종이색, 그림 위에 **얇은 어두운 반투명 판 없이** 먼저 읽히는지 본다(그림이 이미 어두움).
- **이야기 카드**: 6장 중 2번째 = `story-02-source`, 4번째 = `story-04-voices`. 기존 카드 텍스트 자리·판 규칙 그대로. 이야기 4의 얼굴 셋(세로 150~620px 띠)이 글 판에 가려지지 않는지 확인.
- 그림은 손대지 않는다(밝기·자르기 보정 금지). 밝기 문제가 있으면 게임 쪽 판·글 색으로 푼다.
