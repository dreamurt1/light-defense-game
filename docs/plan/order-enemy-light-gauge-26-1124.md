## ① 적 빛 게이지 (`entities/EnemyLightGauge.ts` 또는 `Enemy` 안, `game.json enemyGauge`)

- **대상**: `kind hostile`(박쥐·웨어울프·뱀파이어) · `kind lost`(개구리·고슴도치·레서판다·빛을 잃은 토리·도토). **제외**: `passive`(올빼미·나방·반딧불이 — 세 번 세는 신호가 되어 두 길 균형을 깸), `boss`(노월 — 상단 라벤더 체력바 그대로), 어둠 구슬.
- **보이는 때**: 빛에 맞아 HP가 줄었는데 **아직 0이 아닐 때**만 나타난다(`showMs 1200` 동안 보이고 `fadeMs 300`으로 사라짐, 다시 맞으면 시간 리셋). HP 0(퇴장·구출)이면 그리지 않는다 — 퇴장·구출 연출이 이미 있다. 그래서 한 방에 돌아가는 박쥐(8 ≤ 위력 10)에는 평소 안 뜨고, LP가 약해져 두 방이 될 때만 뜬다(= LP 약해짐이 눈에 보임, 설명 불필요).
- **값**: 채움 비율 = **1 − HP/maxHP**(받은 빛만큼 **차오른다**, 줄지 않는다). 숫자 없음.
- **자리**: 머리 위가 아니라 **발밑**. 걷는 종 = 발끝 기준점 아래 `offsetY 6`px. 나는 종(박쥐·뱀파이어) = 몸 가운데 앵커에서 몸 높이의 절반 + 6px 아래(지그재그에 같이 흔들려도 그림을 가리지 않게). 카메라를 따라가는 월드 그래픽(Phaser)으로 — DOM HUD 아님.
- **모양**: 폭 `width 36` · 높이 `height 4` · 둥근 끝. 바탕 `NIGHT #1B1F3B` 불투명도 0.6, 채움 `AMBER #FFC857`(호스틸·잃어버린 주민 같은 색 — 둘 다 "빛이 스며듦"). 붉은색·EMBER 쓰지 않음. 깜빡임 없음(페이드만). 값이 바뀔 때만 다시 그린다.
- **동시 표시**: 제한 두지 않되, 클라이맥스(동시 8마리+)에서 36×4 게이지가 소음이 되는지 캡처로 확인 → 보고.
- 키 제안: `game.json enemyGauge: { enabled: true, showMs: 1200, fadeMs: 300, width: 36, height: 4, offsetY: 6, kinds: ["hostile","lost"] }`.
