## 3. 밤 1~3 값 — 고쳐 정한다

옛 스테이지 3(7마리)을 밤 3에 그대로 쓰는 것은 과했다. 밤 3은 런 초반(평균 런이 5~8밤)이라 옛 "어둠의 마을" 3스테이지의 난이도를 줄 자리가 아니다. 등불 거리 지적도 맞다. 그래서 둘을 같이 고친다.

**3-1. 고정값 (본 지시서 4절의 `overrides`를 이것으로 교체)**

```jsonc
"overrides": {
  "1": { "normal": { "maxAlive": 3, "interval": [4.0, 3.0] }, "climax": { "maxAlive": 6, "interval": [2.4, 2.0] } },
  "2": { "normal": { "maxAlive": 4, "interval": [3.4, 2.7] }, "climax": { "maxAlive": 7, "interval": [2.0, 1.7] } },
  "3": { "normal": { "maxAlive": 5, "interval": [3.0, 2.4] }, "climax": { "maxAlive": 8, "interval": [1.8, 1.5] } }
}
```

밤 1 = 옛 스테이지 1 그대로(누구나 완전 승리였던 값). 밤 2 = 옛 1과 2의 사이. 밤 3 = 옛 스테이지 2. 밤 4부터는 밤 3 값(5 / [3.0, 2.4], 클라이맥스 8 / [1.8, 1.5])에서 이어지는 단조 증가 곡선 — 출발점 `maxAlive = 5 + 0.7×(n−3)`, `interval = [3.0, 2.4] × 0.92^(n−3)`, 클라이맥스 `8 + 1.3×(n−3)`, `[1.8, 1.5] × 0.92^(n−3)`(상·하한은 본 지시서대로).

**3-2. 빛의 마을(A) 맵의 등불을 광장 쪽으로**

옛 맵의 등불 거리(약 470)에 가깝게, **A 구간 맵(A1·A2·A3)의 등불 자리는 가로·세로 중 큰 값 4~6칸**으로 한다(`obstacles.json lampDist`는 그대로 두고, `nights.json bands[A].lampDist: [4, 6]`을 추가해 밴드별로 덮어쓰기). 지금 7칸인 자리는 광장 쪽으로 한 칸 옮긴다(열, 행): A1 (23,5) → (22,5), (23,13) → (22,13) · A2 (23,4) → (22,5), (23,13) → (22,12) · A3 (23,4) → (22,5). 모두 바닥 칸임을 확인했고 옮긴 뒤 거리는 6칸(약 580px). 옮긴 뒤 `check:maps`. B·C는 4~8 그대로(바깥으로 나갈수록 등불이 멀어지는 것이 테마).

**3-3. 스스로 되돌리는 규칙 (묻지 말고 적용)**

측정에서 실력 0.25가 **밤 3 전에 끝난 런이 12 중 3을 넘으면** 밤 2·3의 `maxAlive`를 1 줄이고 간격을 10% 늘린 뒤 다시 잰다(한 번만). 반대로 실력 1.0이 밤 1~3에서 광원 HP 90% 아래로 떨어진 적이 없으면 그대로 둔다(밤 1~3은 쉬운 게 맞다). 밤 4+ 곡선은 본 지시서 5절 순서로 평균 밤(0.5 → 5~8, 1.0 → 10~12)에 맞춘다.
