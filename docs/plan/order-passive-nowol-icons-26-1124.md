## 2. 배치 계획 (기획)

### 2-1. 나방·반딧불이 — 나는 종

- **자리**: 올빼미와 같은 기존 규칙으로. `art-src/enemies/moth.walk_090_right_f01~04.png` → `moth` 칸 0~3 · `moth-move`; `moth-cower.cower.png` → `moth-cower`; `moth-flee.f01~02.png` → `moth-flee` · `moth-flee-run`. 반딧불이도 같은 꼴(`firefly`). 지시서 이름과 기존 키가 다르면 기존 키를 쓰고 README_claude.md 표에 대조.
- **칸·앵커**: 나방 64px, 반딧불이 48px. 앵커는 **몸 가운데 (0.5, 0.5)** — 올빼미의 발끝 앵커(86%)와 다르다. 그림자는 기존 `CREATURES.*.cy` 규칙대로 몸 아래 바닥에. 날개 때문에 상자 높이가 바뀌어도 중심은 고정(상자 재계산 금지).
- **방향**: 옆 4장만. 이동의 가로 부호로 뒤집기, 세로로만 움직이면 직전 방향 유지(올빼미 도망 규칙과 같음). 앞·뒤 애니 없음.
- **박자**(제안): 날갯짓 8칸/초(올빼미 걷기 6보다 빠르게 — 곤충 느낌), 도망 8칸/초 × 이동 ×1.5. 토리·올빼미와 결이 안 맞으면 조정하고 보고에.
- **나방 도망 폴백**: f01↔f02를 6칸/초로 먼저 돌려 본다. 캡처에서 방향이 깜빡이는 것처럼 보이면 **f02 한 장 고정 + 위아래 ±2px 보브**로 바꾼다. 반딧불이는 f01↔f02 그대로.
- **웅크림**: 정면 1장, 뒤집지 않음, 0.6초.
- 떠 있는 느낌: 나는 종 보브가 이미 있으면 그대로(없으면 ±3px, 2Hz 제안). 반딧불이 배의 빛은 그림으로 충분 — **새 광원·이펙트 시스템은 만들지 않는다**(기능 동결 전 새 시스템 금지).

### 2-2. 노월

- `reference/Nowol_Pack/*.png` → 규격서 4절 표대로: `witch` 시트 0~3 = `witch_idle_calm`(한 장을 네 칸에; 게임이 위아래로 띄움) · 4~5 = `witch_cast_calm` · 6 = `witch_calmed`. `witch-angry` 시트 0~3 = `witch_idle_angry` · 4~5 = `witch_cast_angry` · 6 = `witch_calmed`(공용). 칸 192px, 발끝 97%, 좌우 뒤집지 않음.
- **진정 연출**(calmed 그림이 idle과 거의 같으므로): 진정 순간에 ① 말풍선 "…조금은 믿어 볼게"(이미 있음) ② 기존 `fx-respawn` 계열의 부드러운 빛 한 번 ③ 그다음 6칸 고정. **새 이펙트는 만들지 않는다.**
- 시전 4~5칸은 둘 다 cast 한 장(기존 규칙).

### 2-3. 아이콘

- `reference/UI_Icons_v3/*.png` → UI 아이콘 자리(규격서 5절). id 대응: `lamp_oil` ↔ `icon-prep-lamp-oil`, `spare_heart` ↔ `icon-prep-spare-heart`, `big_pouch` ↔ `icon-prep-big-pouch`, `extra_charm` ↔ `icon-prep-extra-charm`.
- 쓰는 벌: **HUD의 ✦·★ = 선**. **아침 요약·상점 = 산 것/켜진 것은 `-on`, 아닌 것은 선**. **두 길 점 = 선만** — `icon-path-keep` ↔ 자비(mercy) 길, `icon-path-expand` ↔ 돌려보냄(banish) 길. 뒤집지 말 것. `-on` 길 아이콘 둘은 이번 판에 쓰지 않는다.
- 배지(남색 유리 원)는 지금처럼 게임이 그린다. 표시 크기는 지금 UI 값 그대로, 가장 작은 자리(HUD)에서 28px 이상인지 확인.
