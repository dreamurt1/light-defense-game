# ChatGPT 전달 묶음 — 루미와 두 친구 (라이언용 안내)

쇼케이스 포스터 실루엣과 게임 그림을 위해, 루미·토리·도토의 컨셉아트와 스프라이트를 ChatGPT로 만드는 묶음이에요.

## 들어 있는 것

| 파일 | 내용 | ChatGPT에 올림 |
|---|---|---|
| `light-defense-characters-brief.md` | 세계·그림체·세 캐릭터 설정·만들 것·규격·영문 프롬프트 | O |

| `tori-idle-check.png` | 토리 대기 팩 점검 그림(135° 리본 귀·게임 속 크기) | X (135° 고침 끝남, 11-18) |
| `README.md` | 이 안내(라이언용) | X |

## 쓰는 법

1. ChatGPT에서 **새 대화**를 열고, 위 표에서 'O'인 파일 3개를 한꺼번에 올린다.
2. 첫 메시지: `첨부한 브리프를 읽고, 5절 단계 1의 1번(토리 시안 3가지)부터 만들어 줘. 7절 공통 스타일을 지켜 줘.`
3. 시안이 나오면 마음에 드는 것을 고른다.
   - 예: `토리는 가운데 시안으로. 다음은 도토 시안.`
4. 같은 대화에서 단계 2 → 3 → 4 순서로 이어 간다. 브리프 7절의 영문 프롬프트를 그대로 붙여 넣어도 된다.
5. **포스터만 급하면** 단계 1을 고른 뒤 단계 2의 3·4번(라인업·실루엣)까지만 받아도 된다.

## 2026-11-17 밤 — 토리 대기 팩 점검

받은 토리 대기 8장(`reference/Tori_8_Direction_Pack/Tori_Idle_8D_Pack/`)을 루미 팩과 나란히 재 봤어요.

- **좋아요**: 8장 모두 크기·발끝 높이·가로 가운데가 같고, 배경이 투명하고, 잘린 곳이 없어요.
- **고칠 것 1장**: `tori_idle_135_back_right.png`만 리본과 접힌 귀가 반대쪽(토리의 오른쪽 귀)에 있어요. 나머지 7장은 모두 토리의 왼쪽 귀예요. 게임에서 토리가 오른쪽 위로 걷다 멈추면 리본이 다른 귀로 튀어 보여요.
  - ChatGPT에 올릴 것: 브리프 + `tori-idle-check.png` + 토리 대기 8장 + 컨셉 그림.
  - 메시지: `브리프 7절의 '토리 135° 고치기' 프롬프트대로 이 한 장만 다시 그려 줘.`
- **원인 (브리프 쪽)**: 브리프가 "왼쪽 방향은 오른쪽 그림을 뒤집는다"고 했고, 리본 귀를 "오른쪽 귀 끝이 접힘(보는 쪽 기준)"과 "왼쪽 귀 밑동에 리본"으로 기준을 섞어 적었어요. 둘 다 고쳤어요 — 토리는 뒤집지 않고, 접힌 귀와 리본은 같은 귀(토리의 왼쪽 귀)예요.
- **크기**: 토리가 캔버스 안에서 루미보다 작게 그려졌어요(같은 칸이면 머리 폭이 루미의 82%). 다시 그릴 필요는 없어요. 게임에서 Claude가 토리를 1.22배로 키워 머리를 루미와 맞춰요(제안). 대신 **걷기 팩은 대기 팩과 같은 캔버스(512)·축척·발끝 높이**로 만들어야 해요. 브리프 Step B 프롬프트에 넣어 두었어요.
- **없어도 되는 것**: manifest.json·README.md·`PNG_256/` 폴더. 걷기 팩 때 함께 받으면 좋아요.

## 2026-11-18 — 고친 135° 적용, 다음은 토리 걷기

- 다시 그린 135°를 대기 팩에 넣었어요. 리본과 접힌 귀가 토리의 왼쪽 귀(뒤에서 보면 화면 왼쪽)로 맞아요. 점검 그림: `sketches/tori-135-fix-26-1118-1321/tori-135-fix-check.png`.
- ChatGPT가 1254×1254로 줘서 Claude가 다른 7장과 같게(512×512 · 귀 끝 9% · 발끝 97% · 가로 가운데) 맞췄어요. 받은 원본은 `reference/Tori_8_Direction_Pack/Tori_Idle_8D_Originals/`에 있어요.
- 작은 차이(그대로 써요): 눈이 살짝 보여 225°보다 옆모습에 조금 가깝고, 외곽선 몇 군데에 주황빛 테가 있고, 털이 아주 조금 더 분홍빛이에요. 게임 크기(약 150px)에선 거의 안 보여요.
- **다음: 토리 걷기(Step B)**
  - 올릴 것: 브리프 + 기준 사실서 + `tori-concept.png` + **토리 대기 8장 zip(고친 135° 포함, 512)**.
  - 메시지: `브리프 7절 Step B 프롬프트대로 토리 걷기 팩을 만들어 줘. 첨부한 대기 8장(512×512)과 같은 크기·축척·발끝으로.`
  - 걷기는 프레임끼리 축척이 같아야 해요. 프레임마다 크기가 다르게 오면 Claude가 맞추기 어려우니 512로 받는 게 가장 좋아요.
