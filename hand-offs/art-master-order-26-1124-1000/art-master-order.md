## 3. 흐름

ChatGPT 묶음 완료 → 라이언이 기획 세션(claude.ai)에 전달 → 기획 세션이 규격·그림체 검토(통과 / 재작업 메모) → Claude Code 연결. 재작업이 나오면 ChatGPT는 그 묶음만 고치고 다음 묶음으로 넘어간다(기다리지 않음).

## 4. Claude Code의 우선순위

1. **라이언 플레이 소감 반영, 밸런스(값만), 버그** — 항상 먼저.
2. 완료 기준(`check:acceptance`·`check:maps`·테스트·빌드), 휴대폰 확인, 배포, 문서·스킬 zip.
3. **자리가 있는 그림 연결**(표의 "있음"): 오는 대로, 올빼미 절차(art-check → 자리 → `npm run assets` → 캡처 → `README_claude.md` → 스킬 갱신 → zip). 코드 변경이 없는 그림 교체는 **기능 동결(11-26 23:00) 뒤에도 된다** — 테스트·빌드가 그대로 통과하면.
4. **새 연결**(소품·바닥): 1~3이 비었을 때만, 동결 전에 끝날 때만. 못 끝나면 반쯤 넣지 말고 "다음 판"으로 보고.

코드 그림은 **지우지 않는다**(폴백). 아직 안 온 자리는 코드 그림으로 완성 처리한다.
