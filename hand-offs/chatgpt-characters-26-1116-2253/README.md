# ChatGPT 전달 묶음 — 루미와 두 친구 (라이언용 안내)

쇼케이스 포스터 실루엣과 게임 그림을 위해, 루미·토리·도토의 컨셉아트와 스프라이트를 ChatGPT로 만드는 묶음이에요.

## 들어 있는 것

| 파일 | 내용 | ChatGPT에 올림 |
|---|---|---|
| `light-defense-characters-brief.md` | 세계·그림체·세 캐릭터 설정·만들 것·규격·영문 프롬프트 | O |
| `ref-lumi-sheet.png` | 루미 캐릭터 시트(그림체·시트 형식 기준) | O |
| `ref-lumi-portrait.png` | 루미 초상(초상 자세·축척 기준) | O |
| `README.md` | 이 안내(라이언용) | X |

## 쓰는 법

1. ChatGPT에서 **새 대화**를 열고, 위 표에서 'O'인 파일 3개를 한꺼번에 올린다.
2. 첫 메시지: `첨부한 브리프를 읽고, 5절 단계 1의 1번(토리 시안 3가지)부터 만들어 줘. 7절 공통 스타일을 지켜 줘.`
3. 시안이 나오면 마음에 드는 것을 고른다.
   - 예: `토리는 가운데 시안으로. 다음은 도토 시안.`
4. 같은 대화에서 단계 2 → 3 → 4 순서로 이어 간다. 브리프 7절의 영문 프롬프트를 그대로 붙여 넣어도 된다.
5. **포스터만 급하면** 단계 1을 고른 뒤 단계 2의 3·4번(라인업·실루엣)까지만 받아도 된다.

## 올리기 전에 고칠 수 있는 '제안' 항목

브리프의 해당 줄만 고쳐서 올리면 돼요.

- **토리 이름**: 가칭이에요. 그림에는 영향이 없어요.
- **토리 능력 '빠른 발'**: 지금 게임은 '빠른 손'(다시 쏘는 시간 단축)이에요.
- **공통 별 조각**: 4-4절이에요. 빼도 돼요.
- **도토 등 줄무늬**: 시안에서 비교하게 해 두었어요.
- **별·달·씨앗 의미**: 성격과 함께 정리해 둔 제안이에요.

## 받은 그림 보관과 게임에 넣기

- **컨셉 시안·라인업·실루엣·캐릭터 시트**: `reference/` 아래 새 폴더에 저장하면 돼요.
  - 예: `reference/friends-chatgpt-26-1117-1400/`
  - 폴더 이름의 시각은 저장한 시각으로 해 주세요.
- **스프라이트 zip과 초상**: 같은 폴더에 두고 Claude에게 알려 주면, 루미처럼 게임에 넣어요.
  - 친구용 가져오기 도구는 그때 만들어요.
  - 그 뒤 선택 화면 초상, 맵 위 걷기, 빛을 잃은 모습이 바뀌어요.
- **ChatGPT가 8방향 걷기를 정확히 못 그리면**: 루미 팩처럼 '대기 8방향 + 오른쪽 걷기 4프레임'만 받아도 돼요. 나머지 방향은 변형해서 만들 수 있어요(루미 팩도 이렇게 만들었어요).
