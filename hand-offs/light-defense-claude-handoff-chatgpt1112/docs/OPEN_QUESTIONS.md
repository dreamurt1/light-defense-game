# Open Questions — 사용자 확인이 필요한 기획 사항

다음 항목은 XMind PDF에서 완전히 확정되지 않았거나 구현 시 서로 다른 해석이 가능한 부분이다. Claude Code는 임의로 최종 확정하지 말고 설정값/임시 기본값으로 분리한다.

## 우선순위 높음
1. 플레이어블 캐릭터는 루미/토끼/다람쥐 3종으로 확정인가? (이번 PDF 기준)
2. 토끼와 다람쥐는 각각 어떤 특정 스테이지에서 구출되는가?
3. 보스 스테이지에도 100초 타이머와 중앙 광원 방어를 적용하는가?
4. HP가 0이 되어 하트를 잃은 직후 HP는 얼마로 재생성되는가? 무적 시간은 얼마인가?
5. 등불 활성화에 LP를 소모하는가? PDF에는 활성화 후 플레이어 LP가 감소한다고 적혀 있으나, 활성화 전 잔량과 관계없다는 설명도 있다.
6. 등불이 '활성화'된 뒤 광도는 지속 유지되는가, 적의 공격으로 단계적으로 낮아지는가? 자연 감소도 적용하는가?
7. 중앙 광원은 HP를 별도로 갖는가, 광도/LP만으로 상태를 표현하는가?
8. 일반 승리 조건의 '플레이어 HP가 남아 있음'은 하트가 1개 이상 남아 있다는 뜻인가?
9. 패시브 주민 자비 점수는 주민당 한 번만 받을 것인가? 자비 점수의 보상량은 어느 정도인가?

## 우선순위 중간
10. '별 목걸이'가 적 이동속도 감소 아이템으로 정의되어 있다. 기존 콤보 유지 아이템과 혼동되지 않도록 이름/효과를 확정할 것.
11. 빛의 부적은 기본 제공 소모형 아이템인가, 장착형인가?
12. 황금 도토리가 소환하는 주민은 어떤 행동을 하는가? 공격 대상/지속시간/소환 수는?
13. 적 필살기의 방어력 증가는 적 자신의 방어력인가, 플레이어 방어력인가?
14. 맵 3종은 별도 스테이지 테마인가, 한 맵 안의 지역 구획인가?
15. 풀숲 은신은 플레이어만 적용되는가, 적도 적용되는가?
16. 아이템 스폰 조건에서 '모든 등불이 꺼짐'과 '중앙 광원 주변 적이 일정 수 이상'은 예외 스폰 규칙으로 보인다. 우선순위/최대 아이템 수는?
17. 적이 빛을 받았을 때의 이동속도 저하/회피/움찔 효과는 몹별로 어떻게 다른가?

## 기술/배포
18. 현재 저장소의 기술 스택과 Firebase 프로젝트 구성은 무엇인가? 기존 코드를 조사한 후 결정.
19. 계정/랭킹/상점/광고는 초기 배포에 포함하는가, 이후 업데이트인가?
20. 모바일 세로형을 완전 지원할 것인가, UI 간소화 또는 회전 안내로 처리할 것인가?
