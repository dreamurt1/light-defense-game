# Acceptance Criteria & Test Checklist

## A. 실행과 화면
- [ ] 기존 프로젝트의 공식 개발 명령으로 로컬 실행 가능
- [ ] 브라우저 콘솔에 반복적인 오류가 없음
- [ ] 게임 화면이 창 크기 변경에 대응
- [ ] 가로형/세로형 레이아웃에서 UI가 잘리지 않음
- [ ] 모바일 터치 중 페이지 스크롤/새로고침 제스처가 게임 입력을 방해하지 않음

## B. 이동과 공격
- [ ] 좌측 가상 스틱으로 360도 이동
- [ ] PC에서는 마우스/키보드로 테스트 가능
- [ ] 우측 드래그로 공격 방향과 반경 표시
- [ ] 손을 떼면 공격 발사
- [ ] 이동 중에도 공격 가능
- [ ] 반자동 공격이 켜져 있을 때 대상이 없으면 오발/비정상 방향 공격이 발생하지 않음
- [ ] FPS가 달라도 이동 속도와 쿨다운이 동일

## C. HP / 하트 / LP
- [ ] 피격 시 HP가 감소하고 LP는 직접 감소하지 않음
- [ ] HP가 0이면 하트 1개 감소
- [ ] 하트가 남아 있으면 중앙 광원 근처에서 재생성
- [ ] 하트 소진 시 패배
- [ ] LP는 최저 '낮음' 상태 아래로 내려가지 않음
- [ ] LP가 낮아도 플레이가 완전히 불가능해지지 않음
- [ ] 중앙 광원/활성 등불 근처의 LP 회복 속도가 구분됨

## D. 등불과 중앙 광원
- [ ] 비활성 등불에 빛 공격 적중 시 활성화 예약/전환
- [ ] 활성 등불이 적의 공격을 받으면 광도 감소
- [ ] 중앙 광원이 공격받으면 상태가 감소
- [ ] 중앙 광원이 최저 상태에 도달하면 패배
- [ ] 모든 등불 활성화 시 맵 전체 광도 버프
- [ ] 외곽 등불을 켜는 전략이 실제 이점을 제공

## E. 주민과 적
- [ ] 잃어버린 주민은 빛에 의해 구출되고 귀환 애니메이션 재생
- [ ] 일반 호스틸 몹은 HP 0에서 퇴장
- [ ] 호스틸 몹은 중앙 광원 또는 등불을 위협
- [ ] 패시브 주민은 플레이어를 공격하지 않음
- [ ] 패시브 주민을 공격해도 점수/아이템 이득이 없음
- [ ] 패시브 주민 가까이를 공격하지 않고 지나가면 자비 점수
- [ ] 자비 점수가 반복해서 무한 획득되지 않도록 1회 판정/쿨다운 적용

## F. 스테이지와 점수
- [ ] 일반 스테이지 타이머가 설정된 시간에 종료
- [ ] 70% 진행 시 클라이맥스 스폰 변화
- [ ] 기본 승리와 완전 승리가 구분
- [ ] 완전 승리 조건 달성 시 추가 보상
- [ ] 보스 스테이지의 승리/패배 규칙이 별도 설정으로 동작
- [ ] 점수, 콤보, 자비 점수가 결과 화면에 정확히 반영

## G. 아이템
- [ ] 소모형 아이템을 획득하고 지정된 횟수만 사용
- [ ] 아이템 효과가 지속시간 종료 후 정상 해제
- [ ] 아이템이 플레이어/등불/중앙 광원과 겹쳐 획득 불가능한 위치에 생성되지 않음
- [ ] 아이템 스폰은 맵의 광도와 등불/경계 지역 규칙을 반영

## H. 저장과 배포
- [ ] Firebase 설정이 소스에 비밀키 형태로 노출되지 않음
- [ ] 로컬 빌드 성공
- [ ] Firebase Hosting 배포 성공
- [ ] 배포 URL에서 새로고침 후 앱이 정상 로드
- [ ] 모바일 Chrome/Safari에서 기본 플레이 가능
